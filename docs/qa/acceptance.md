# 验收规格

本页是可复用的方法与需求映射，**不是已通过的验收报告**。当前尚无正式产品可执行程序；仓库中的可运行技术试验不等于产品实现，下面的产品运行验收均待实现后执行。

## 按改动选择验证

| 改动 | 验证范围 |
| --- | --- |
| 文档与材料 | 本地链接、JSON、图片存在、SHA-256、原稿引用、默认值一致性 |
| 文档模型与文件 I/O | 真实输入、版本与撤销、保存失败、冲突、权限、竞态及取消／退出 |
| UI 与设置 | 实际鼠标、键盘、辅助功能、焦点、跨窗口同步与跨启动持久化 |
| 渲染 | 固定语法样例、过期结果、本地资源边界、脚本拒绝与复杂度限制 |
| 系统与平台包 | 原生打开事件、多进程转发、关联、独立运行目录、安装／升级／卸载 |
| 视觉 | 同逻辑尺寸的真实窗口对照、字体／密度／菜单、多主题与长文案 |

## 文件与保存场景

- 写前外部变化、保存过程中外部替换、原文件删除、权限撤销、磁盘空间不足、临时文件失败、卷断开。
- 保存期间再次输入，旧回执不得把新修改标为 clean；冲突后自动保存停止，不循环覆盖磁盘版本。
- 同目录替换后的监测事件不触发错误重载；另一个窗口或进程的真实修改仍可发现。
- 干净文档阅读前后字节不变；不能因读取而改编码、换行或末尾空行。
- 保存失败和结果不确定分开核对实际磁盘字节；仅“界面显示错误”不证明旧文件完好。
- 符号链接、硬链接、大小写别名和网络文件系统有单独的平台适用范围，不从普通文件推断。

使用自行生成且可分发的样本，不把用户文档、私人路径和访问凭据放进公开记录。

## 主题、尺寸与平台矩阵

| 维度 | 最低验证组合 |
| --- | --- |
| 主题 | 浅色、深色、跟随系统实际切换 |
| 强调色 | 全部六色；主要按钮、色块选择、开关与语义状态分别核对 |
| 字号 | 应用辅助字号 100%／125%／150%，正文单独增大 |
| DPR | 1、1.25、1.5、2，设备不具备的组合明确未执行 |
| 窗口 | 默认、最小、长文案、设置正文滚动、菜单靠屏幕边缘 |
| 平台 | Windows、macOS、Linux 的实际选定系统与架构，不由 CI runner 名称代替支持政策 |

记录平台、源码身份、逻辑窗口、DPR、字体与渲染后端。PNG 物理尺寸不能证明逻辑几何正确，离屏窗口、容器和截图工具不能冒充真实桌面人工验收。

辅助功能验证须执行控件动作并核对真实选择模型、主题或文件行为，不能只读取 checked。跨平台快捷键、菜单焦点、默认应用跳转和系统标题栏分别验证。

## 公共组件跨界面检查

实现后，从工作区、独立文件、设置及实际包含对应组件的辅助窗口或弹窗中，选择至少两个出现同一组件的界面进行对照；若某界面没有该组件，记录其不适用，不为凑齐检查而新增控件。检查范围包括顶部栏、标题栏、窗口操作与关闭按钮、底部状态栏／页脚、标签、图标和共享基础控件。

在同一平台、主题、强调色、字号、DPR 和交互状态下，检查同类组件的逻辑尺寸、相对锚点、边距、基线、图标比例、命中区域和状态样式是否符合[设计系统](../visual/design-system.md#跨界面公共组件一致性)及共享参数。依照上面的矩阵核对主题、强调色、字号和窗口伸缩；不同主题使用各自映射的颜色，不要求截图像素完全相同。已登记的语义或平台变体分别核对，原生窗口装饰以实际平台约定为准。

同时检查鼠标点击不留下额外焦点外框，Tab／Shift+Tab 需要时可辨认焦点，激活、取消、指针操作或失焦后外框消失；逻辑焦点、文本光标和选中状态按[控件交互规则](../product/control-interactions.md)保留。记录实际比对的窗口、组件、状态及未执行的组合，不能用静态图板或共享代码本身代替运行与人工视觉验收。

## 证据与结论

运行截图、日志、测量 JSON、性能数据和临时输入放在 `build/` 或 CI 工件，不加入 `docs`。任务系统记录本次结果、来源、未执行项和后续责任；本页保留方法。

文档完整、功能检查、几何检查、人工视觉、系统集成和发行复核是不同结论。只有实际执行的路径能标记通过，任何一项都不自动替代其他项。
