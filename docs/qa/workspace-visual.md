# 工作区界面核对

本清单用于检查工作区及其新增导航页。参照[浅色工作区](../../design/hifi/v2/boards/01-workspace-light.png)、[深色工作区](../../design/hifi/v2/boards/02-workspace-dark.png)及[导航状态](../../design/hifi/v2/boards/08-navigation-states.png)，精确几何和颜色以[共享参数](../visual/tokens.json)与[视觉规范](../visual/design-system.md)为准。静态图存在入口不代表该功能已经实现，完整设置、资源与链接、全文搜索等范围按[工作区基础](../engineering/workspace-foundation.md)区分。

## 外壳与边界

在明暗主题下分别检查空工作区、编辑、阅读、双栏、最近打开、收藏及文件名搜索。常规宽度与紧凑宽度均保留可达的文件、保存、关闭和视图操作。

| 区域 | 要求 |
| --- | --- |
| 标题行与标签 | 标题行 48；标签顶部贴齐标题行，无额外留白；活动标签上、左、右有主题细边，底边与内容面连接；非活动标签下方、空白区域及溢出区的底边连续。零标签时隐藏标签与加号，保留品牌、窗口按钮和连续底边，空白区域可拖动。切换、重排、悬停和关闭后规则不变。 |
| 标签状态 | 图标、未保存圆点、文本、关闭按钮共用统一基线和命中；非活动标签有悬停，溢出按钮使用当前主题，长名省略保留完整提示。 |
| 侧栏与内容 | 默认侧栏宽 224，分隔线覆盖侧栏全高，不能在文件树、导航页、空状态或底部设置附近断开；收起侧栏时分隔线一并隐藏。 |
| 工具栏与内容 | 工具栏 48，格式栏和预览标题各 36；横线、双栏分隔及状态栏上边按容器边缘对齐，使用主题 `border` 色，不出现原生白色凸起线。 |
| 状态栏 | 高 26、横跨窗口；切换活动文档后内容跟随，导航页不显示非活动文档的保存或光标状态。 |

## 导航与交互

| 区域 | 要求 |
| --- | --- |
| 侧栏层次 | 依次为工作区选择、搜索、最近打开、收藏、文件夹与树，底部为设置和主题。刷新及全文搜索收在工作区菜单，不插入额外常驻全文搜索按钮；文件夹加号请求选择目录。 |
| 文件树 | 目录箭头、文档图标、层级缩进和长名省略一致；选中为完整浅填充与细标记，正文色文字保持可读。加载、空、缺失及无权限均有明确反馈。 |
| 面包屑 | `文档 / 子目录 / 文件名.md`；根目录文件、工作区外文件和未绑定目录分别核对。另存为或更换工作区后更新；绝对路径只保留在完整提示和位置操作中。 |
| 最近与收藏 | 结果行包含文件名、相对层级、时间及星标；最近按今天、昨天、更早分组。文件缺失有提示，打开失败不伪造成功；收藏变化同步其他工作区。 |
| 搜索与空状态 | 搜索限文件名，支持清除；等待、无匹配、不完整结果明确区分。空状态使用统一图标、标题、说明与动作，不能只在内容区摆一行文字。 |
| 主题与菜单 | 侧栏主题按钮和设置中的现有外观菜单实际生效；系统／明暗主题与六种强调色同步。保存偏好失败时恢复勾选并反馈。 |
| 焦点与会话 | 指针不出现 focus outline；Tab 导航需要时显示，激活／取消／失焦后隐藏。搜索快捷键可展开侧栏；导航页切回标签保留原文、撤销、选区和滚动。 |

## 证据与限制

`workspace_workflow` 使用自建 Markdown 工作区，核验相对路径、会话连续性、导航持久化与失败恢复、主题像素和边界位置。截图使用稳定的 `light-split.png`、`dark-split.png` 及相应 `recent`、`favorites`、`search-empty` 状态名，进入构建目录下的 `evidence/workspace/`；替换同用途旧图，不存入设计目录或源码。

必须实际查看本次运行截图，不能只凭控件几何或测试退出码判断视觉正确。像素检查、人工视觉、真实输入法、原生辅助技术与物理跨屏分别记录；未执行的项目继续保留，不能在本清单中写成已经通过。

Windows 的离屏复核进程需显式提供系统字体目录，例如临时设置 `QT_QPA_FONTDIR=C:/Windows/Fonts`；截图入口检查拉丁与中文字形，缺字方框不作为可验收截图。使用固定 Qt 6.8.2 的 `offscreen:configfile=<本周期 JSON 的相对路径>` 设置足够的虚拟屏幕，例如 `{"screens":[{"name":"review","width":1920,"height":1080,"logicalDpi":96,"logicalBaseDpi":96,"dpr":1}]}`。常规窗口与低可用区场景分别采样，不能把插件默认的小屏幕收敛结果当作正常宽度布局；这些设置仅用于测试进程，不修改系统缩放或真实显示器配置。
