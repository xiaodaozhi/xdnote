# 无交互桌面的自动验证

本范围使用自生成输入、临时文件和 Qt `offscreen` 平台，不需要解锁、窗口激活、真实输入、UIA 或系统选择器。锁屏时电脑须保持唤醒；休眠会暂停本机进程。验证不操作用户文档，不修改系统 PATH。

## 运行与证据

先按[开发构建](../engineering/developer-build.md)完成本项目构建，再运行：

```text
python scripts/desktop.py test --suite background --build-dir build/desktop-admission --qt-prefix build/Qt/6.8.2/msvc2022_64
```

上例为 Windows；macOS SDK 子目录为 `macos`，Linux 为 `gcc_64`。入口核对构建身份与源码摘要，固定 1920×1080、96 DPI、DPR 1 的离屏屏幕。Windows 显式指定系统字体目录；缺失中文或 emoji 字形不能记为通过。

`<构建目录>/evidence/background/` 保存原始日志、明暗截图与 `report.json`。报告记录构建身份、验证脚本与预算摘要、宿主、每组 QtTest、每份样本的 SHA-256、逐次耗时、P50／P95、内存指标及未覆盖项。失败也保存已完成结果与错误；非零退出、跳过、缺失报告、Qt critical／fatal 或断言均不算通过。超时只结束本次创建的诊断进程树。

## 覆盖与性能口径

- 原生预览：全局语义、连续滚动、跨块选择／复制、代码和表格独立横向滚动、失效请求、资源撤销、后台布局、只读辅助接口及明暗共享参数。另用实际 `MarkdownPreview` 检查中文、任务列表、代码和 HTML 原文、选择复制、源文不变并生成明暗截图；截图不自动构成人工视觉验收。
- 会话与文件：字节保真、撤销、合成组合输入、只读拒绝、线程与生命周期、跨窗口接管、保存冲突、硬链接保护、替换竞争和保存期间继续编辑。
- 几何：DPI 换算、往返不增长、负坐标可用区、尺寸不足及持久化失败；不移动原生窗口。
- 性能：10 KiB、1 MiB、2 MiB 混合语法样本，测量原生模型解析与投影、受限 HTML 派生输出、引用、标题、会话修改／撤销、文件读取与原子保存。HTML 只是 Rust 服务输出测量，不加载浏览器。各项独立进程，预热一次后计时七次；最近秩 P50 是排序后第四次，P95 是第七次。
- 容量与资源：10 MiB 仅验证解析／文件入口拒绝，不进入编辑会话；密集引用验证复杂度拒绝。另测 600 万像素静态图片解码、128 份自有文档扫描及预先取消请求不发布来源快照。源文和派生输出上限不因测量而放宽。

预算由 [background-budgets.json](../../tools/background-budgets.json)锁定，属于后台回归护栏，不是产品体验承诺。内存为隔离工作进程的峰值工作集（Windows）或 RSS（Unix），不包含资源助手或完整应用；不能与私有提交量混用。预览就绪耗时也不是冷启动、真实键入或滚动延迟。宿主、字体、存储和并发负载变化后，不直接横比不同机器的性能值。

## 平台边界

手动选择桌面工作流的 `scope=background-unix`，只验证 Linux、macOS Intel／ARM 的本范围，不运行完整桌面矩阵或 Windows 兼容配置。普通提交与合并仍只运行材料 CI。

真实输入法、读屏软件、原生选择器、文件管理器转交、焦点激活、拖放／剪贴板、物理跨屏、最低系统和安装升级仍需对应环境单独验证。已有通过证据不因新增入口而无条件重跑；离屏结果不能替代上述验收。
