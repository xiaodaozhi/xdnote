# 无交互桌面的自动验证

本范围使用自生成输入、临时文件及 Qt `offscreen` 平台，不依赖解锁、窗口激活、真实键盘鼠标、UIA 或系统文件选择器。锁屏时电脑须保持唤醒；休眠会暂停本机进程。运行不修改系统 PATH，不启动产品窗口，也不操作用户文档。

## 入口与证据

先按[开发构建](../engineering/developer-build.md)准备本项目工具并完成构建，再运行：

```text
python scripts/desktop.py test --suite background --build-dir build/desktop-admission --qt-prefix build/Qt/6.8.2/msvc2022_64
```

上面为 Windows SDK 路径；macOS 使用 `macos`，Linux 使用 `gcc_64`。入口核对构建来源及 Qt 版本，显式设定 1920×1080、96 DPI、DPR 1 的离屏环境。Windows 同时指定系统字体目录，缺失中文字形时不生成通过结论。继承的交互平台和采样倍率不能改变此范围。

`build/<所选构建目录>/evidence/background/` 保存报告、原始日志、明暗排版截图及逐次测量。`report.json` 携带构建身份、平台、样本 SHA-256、期望结果、耗时、P50、P95、进程峰值内存与未覆盖项；失败时也保存已完成部分，`ok` 保持 false。诊断超时只结束本次创建的进程树，不清理用户正在运行的应用。

## 自动化范围

- 文档会话：字节保真、撤销、合成组合输入、只读拒绝、辅助功能线程与生命周期、独立窗口至工作区接管。Qt 辅助接口验证不涉及真实读屏软件。
- 文件：自有临时文件的保存、冲突、硬链接保护、替换竞争、迟到保存回执与保存期间继续编辑。
- 几何：125%／150%／200% 等确定性计算、往返不增长、负坐标可用区、尺寸不足与持久化失败；不执行原生窗口移动和物理多屏测试。
- 性能：10 KiB、1 MiB、2 MiB 自有 UTF-8 混合语法样本，分别测量 Rust 渲染、引用、标题、会话修改／撤销及实际文件读写。每项在独立进程运行，预热一次，七次计时，P95 使用最近秩法（七次中的最大值）。文件测量包含读取、校验和原子保存。
- 限制：10 MiB 样本只用于验证解析和文件入口拒绝，不能进入编辑会话；2 MiB 高密度引用验证复杂度限制。源文上限与派生输出上限分别核对，不因测量而放宽。
- 资源：600 万像素静态图片解码、128 份自有文档的引用扫描，以及已取消请求不发布来源快照。
- 排版：明暗受限 Web 预览核对中文字体、标题、表格／代码横向溢出、代码原文、任务列表、HTML 转义、脚本不执行、远程链接／图片不自动激活，以及原文不变。

性能值依赖宿主、字体、存储和并发负载，不跨不同 CI 宿主直接比较。进程峰值 RSS 不含 WebEngine／资源助手子进程，因此不是产品总内存。预览 `readyMs` 是离屏首个结果就绪时间，不能称为冷启动、真实键入或滚动延迟。

自动化护栏锁定在 [background-budgets.json](../../tools/background-budgets.json)：每个 QtTest 组在 150 秒内结束，每个独立测量进程在 60 秒内结束，工作进程峰值 RSS 不超过 512 MiB；P95 上限为渲染／引用 5 秒、标题 2 秒、会话修改与撤销 250 毫秒、文件读写及图片解码 2 秒、128 文档扫描 30 秒、已取消请求 100 毫秒。离屏预览首次就绪上限为 20 秒。测试须无失败、跳过、Qt critical／fatal 或断言。以上是后台回归护栏，实际输入延迟、整应用内存和用户体验预算须在真实桌面继续确定。

## 跨平台与剩余验收

手动选择桌面工作流的 `scope=background-unix`，只运行 Linux、macOS Intel／ARM 的本范围，不运行完整桌面用例、Windows 兼容配置或技术试验。普通提交与合并仍只运行材料 CI。

真实中文输入法、读屏软件、原生选择器、文件管理器转交、焦点激活、实际拖放与剪贴板、物理多屏、最低系统及安装升级仍分别保留。已有视觉验收不因新增后台入口而重新请求确认；离屏截图不替代真实桌面验收。
