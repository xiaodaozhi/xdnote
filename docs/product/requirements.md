# 产品需求

## 定位与用户场景

xdnote 是以本地 Markdown 文件为中心的跨平台阅读与编辑器。面向记录笔记、阅读项目文档、整理知识和编写技术说明的用户。文件可以独立于工作区存在，应用不会要求用户先导入资料库才能阅读。

核心场景：双击一个文件快速阅读；在原文件上修改并可靠保存；在工作区处理多个文档；按个人习惯调整明暗与强调色。

## 首版需求

P0 是首版闭环，P1 在基础闭环稳定后安排。表内均为待实现需求。

| ID | 优先级 | 需求与完成边界 |
| --- | --- | --- |
| FR-01 | P0 | 工作区可显式打开本地目录、导航 Markdown 文件、使用标签页；文件本身不搬入私有数据库 |
| FR-02 | P0 | 系统关联、应用内打开和文件拖入使用统一打开路由；系统双击默认独立窗口 |
| FR-03 | P0 | 主工作区支持编辑、双栏、阅读；独立窗口支持阅读与编辑，切换不丢失缓冲区、光标与可恢复的滚动位置 |
| FR-04 | P0 | 支持标题、段落、强调、列表、引用、链接、图片、围栏代码、任务列表与表格；具体 Markdown 方言和渲染器经验证固定 |
| FR-05 | P0 | 新建、保存、另存为、未保存提醒、保存失败和外部修改冲突构成完整文件闭环 |
| FR-06 | P0 | 浅色、深色、跟随系统与六种强调色独立设置，主界面、独立文件和设置窗口一致响应 |
| FR-07 | P0 | 设置即时生效并持久化，提供清晰默认值、非法配置回退和失败反馈 |
| FR-08 | P0 | 为 `.md`、`.markdown` 提供打开方式注册与用户主动设置默认应用入口，安装不静默抢占关联 |
| FR-09 | P1 | 最近文件、收藏、工作区文件名筛选；全文搜索另行定义范围，不由图中的搜索框推定 |
| FR-10 | P1 | HTML／PDF 等导出能力专项设计并验证；当前图中的「导出」是预留入口 |

正文内的任务复选框在阅读模式下只展示状态，不直接修改源文件。渲染后的正文不提供所见即所得编辑，首版编辑以 Markdown 源文为准。

## 数据与兼容边界

- 首版以 UTF-8 与 UTF-8 BOM 文件为基本输入，保留既有 BOM 和 LF／CRLF。未知或损坏编码不静默替换字符后覆盖保存，显示只读反馈或明确的重新打开入口。其他编码由后续兼容任务定义。
- 同一文件在不同打开入口间共享文档身份。路径规范化用于去重，不等于额外目录授权；硬链接、符号链接与网络文件系统的身份规则需要原生验证。
- 阅读不会整理、重排或写回源文；切换视图、主题与配色也不改变文件内容。
- 图片与链接以当前文档目录为解析上下文，不默认获取网络图片或执行嵌入脚本，详细边界见[架构草案](../engineering/architecture.md)。

## 质量要求

| ID | 要求 |
| --- | --- |
| NFR-01 | 保存成功、未保存与冲突状态准确；未保存内容不因窗口路由、异步回调或关闭而无提示丢失 |
| NFR-02 | 中文输入法、组合输入、撤销重做、选区和键盘操作完整；阅读与编辑字号独立于系统 DPR |
| NFR-03 | 保存、解析、监测文件变化不阻塞持续输入；过期渲染结果不得覆盖新版本 |
| NFR-04 | 使用真实原生窗口核对多窗口、文件关联、缩放、菜单和辅助功能，离屏检查不替代人工桌面验收 |
| NFR-05 | 默认本地处理文档，无需账号；首版不设置后台遥测或云端同步前提 |

性能基准使用自有 10 KiB、1 MiB、10 MiB 文本样本，收集启动、输入、渲染、保存耗时及内存。性能预算和支持上限在技术验证后固定，不能把样本大小写成已经承诺的最大文件能力。

## 首版范围外

云同步、账号体系、多人协作、插件市场、AI 助手、富文本双向编辑、跨设备历史、Git 客户端、数学／图表扩展、任意 HTML 执行与自动更新均不属于当前首版闭环。后续加入时补充需求、依赖和验收，而非仅启用设计图按钮。

## 仍需决策

- 框架、Markdown 解析器、渲染承载与桥接方式。
- 工具链与包类型；最低系统、CPU 架构和 Linux 图形环境已按[平台基线](../engineering/platform-support.md)确定目标，尚待产品验证。
- 首次启动主题与强调色的最终默认值；当前材料使用 system 与 graphite。
- 未知编码、超大文件、文件系统竞争及恢复草稿的具体支持边界。
- 独立图标库、字体来源、许可证及发行策略；已确认的应用品牌图标仍需原生平台验证。

对应交互见[交互规格](interaction-spec.md)，验证入口见[验收规格](../qa/acceptance.md)。
