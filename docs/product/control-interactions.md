# 控件交互与焦点显示

本文定义研发前的交互规则，适用于主工作区、独立文件、设置、弹窗、菜单及共享控件。当前只定义预期行为，不表示已有实现。

## 默认规则

常规鼠标／触控点击、悬停、按下、拖动和程序自动聚焦不显示 focus outline。控件通过轻微底色、按下反馈、光标或选择标记表达状态，不在点击后长期留下额外外框。

只有用户按 Tab 或 Shift+Tab 移动到控件、且确需辨认当前位置时，才显示该目标的键盘焦点外框。同一窗口最多突出一个 Tab 目标，不给整组控件或面板同时加框。

## 出现与消失

| 事件 | 焦点外框 | 保留的行为 |
| --- | --- | --- |
| 鼠标／触控悬停、按下或点击 | 不显示；指针按下时清除已有外框 | 悬停和按下底色、正常动作、实际选择 |
| Tab／Shift+Tab 移动到控件 | 按需要显示当前目标的外框 | 可继续使用键盘操作 |
| Enter／Space 激活按钮、开关或选项 | 动作触发后隐藏 | 逻辑焦点保留，下一次 Tab 可继续 |
| Esc、取消、点击空白、关闭菜单／弹窗 | 隐藏 | 按交互语义返回调用控件，不自动重新画框 |
| 控件失焦或窗口失活 | 隐藏 | 不留下残影，重新激活不自动恢复旧框 |
| 程序自动聚焦，例如打开搜索或弹窗 | 不显示 | 输入框可显示插入光标，下一次 Tab 才建立外框 |
| 方向键在菜单、列表、分段内移动 | 不额外新增外部 outline | 当前行高亮、选项状态和可读名称 |

隐藏外框时不能强制 blur、清空选区、破坏输入法、取消实际选择或重置 Tab 顺序。文本框中的普通输入、组合输入和编辑快捷键不按按钮激活处理；后续指针、取消或失焦仍清除外框。

## 与普通边线的区别

- 输入框的单层细边线、窗口边界和菜单分隔线属于结构，不是额外 focus outline。
- 错误字段的语义边线、当前配色勾选、文档选中标记、复选框、单选圆点和文本光标按各自状态保留。
- 主题、配色和标签的选中状态优先使用勾选、填充或细标记，避免用粗重双层外框常驻表达选择。
- 中文组合输入下划线、文本选区及系统输入法候选框不被按钮外框规则抹除。
- 禁用控件不接收交互焦点，不显示外框；只读字段仍可供选择与复制。
- Tab 外框沿用当前强调色及[共享视觉参数](../visual/tokens.json)中的线宽与留白，不另设窗口专用样式。

## 共享实现要求

后续由共享交互层记录 Tab 导航目标和外框可见性，将视觉外框与逻辑焦点分别处理。不能直接使用无条件 `:focus`；默认 `:focus-visible` 也不完全等价于本产品规则，因为部分输入框被鼠标点击时仍可能显示它。

动作激活、取消、指针输入、失焦与窗口失活走统一清除规则。设置、工作区和独立窗口遵循同一约定，不串用其他窗口的旧 Tab 目标。

## 后续核对场景

鼠标依次点击按钮、文本框、下拉、开关、复选框、单选、滑块、标签和菜单后没有残留外框；Tab／Shift+Tab 可辨认当前目标；Enter／Space 激活和 Esc 取消后外框消失；下一次 Tab 从合理位置继续。弹窗关闭、窗口失活、输入法组合输入和只读字段分别核对。

现有设计图中的焦点样式只作为 Tab 导航状态的形态参考，不能据此推导为常驻点击效果。
