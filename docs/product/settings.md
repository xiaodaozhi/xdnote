# 设置规格

设置使用单一独立非模态窗口，从工作区或独立文件窗口进入时聚焦同一实例。当前[通用与编辑器](../../design/hifi/v2/boards/11-settings-general-editor.png)、[外观与阅读](../../design/hifi/v2/boards/12-settings-appearance-reader.png)、[快捷键与关于](../../design/hifi/v2/boards/13-settings-shortcuts-about.png)和[深色](../../design/hifi/v2/boards/14-settings-dark.png)均已有静态设计，反馈状态见[完整清单](../visual/screen-inventory.md)。

## 分类与作用域

| 分类 | 内容 |
| --- | --- |
| 通用 | 外部文件打开目标、独立窗口初始模式、文件关联、保存偏好 |
| 外观与配色 | 明暗主题、强调色、当前控件效果预览 |
| 编辑器 | 字体、字号、软换行、缩进，具体范围按技术验证确认 |
| 阅读与渲染 | 阅读字号、行距、正文宽度及内容显示偏好 |
| 快捷键 | 首版展示平台快捷键；自定义映射在单独定义后提供 |
| 关于 | 产品版本与来源；应用版本建立后再填真实值 |

通用和外观为应用级偏好。光标、选区、滚动位置和临时视图属于文档／窗口状态，不混入全局配置。首版不提供工作区覆盖应用配置的继承链。

## 主题与强调色

`appearance.theme` 取 `light`、`dark`、`system`，暂定 `system`。跟随系统仅改变明暗，不替用户更换强调色。

`appearance.accent` 使用下列稳定标识，名称仅用于展示。精确色值及明暗变体以 [tokens.json](../visual/tokens.json) 为唯一来源。

| 标识 | 名称 | 状态 |
| --- | --- | --- |
| graphite | 石墨灰 | 当前原稿展示默认值，首次启动默认值暂定 |
| mist-blue | 雾蓝 | 可选 |
| cobalt | 钴蓝 | 可选 |
| mauve | 灰紫 | 可选 |
| terracotta | 陶土 | 可选 |
| olive | 橄榄 | 可选 |

选择项同时显示名称、色块和非颜色标记；当前项以勾选表达单选状态。色值标签显示基准色，暗色界面使用同色系适配值，效果预览反映实际当前主题。

强调色作用于主要按钮、分段选中项、开关、选中标记、焦点与文档中的适度装饰。它不重定义错误、警告、已保存等语义颜色，也不强制把代码语法高亮全部染成一种颜色。切换影响所有已打开窗口及后续窗口，不修改 Markdown 内容。

界面主题与强调色分别选择，初期没有自定义 HEX 输入、任意调色盘或额外主题下载。六个候选保留，不能因当前原稿为石墨灰而删去其他选项。

## 打开与保存偏好

以下为设计默认值，不是已经实现的配置文件。

| 字段／策略 | 默认值 | 生效边界 |
| --- | --- | --- |
| `desktop.externalOpenTarget` | `standalone` | 外部入口可选择 `standalone` 或 `workspace-tab`，仅影响新会话 |
| `desktop.standaloneDefaultMode` | `reading` | 可选 `reading`／`source`，已有文档视图不随设置跳转 |
| 重复文件策略 | 激活已有会话 | 首版固定安全行为，不提供创建独立可覆盖副本的选项 |
| `editor.wordWrap` | `true` | 仅影响源文呈现，不插入换行 |
| `editor.autoSave.enabled` | `false` | 启用后使用与手动保存相同的冲突和提交服务 |
| `editor.autoSave.delayMs` | `1500` | 暂定停止输入后的防抖时间，需性能验证 |
| `files.confirmUnsavedClose` | `true` | 首版保留关闭保护；无可靠恢复方案前不开放静默丢弃开关 |

重复打开与关闭保护按上表收敛：只有一个有效值的策略不展示空的下拉选择，不开放会无提示丢失修改的设置。自动保存不替未命名文档猜测路径，保存冲突与只读状态下暂停自动写入并给出反馈。

「设置默认应用」进入平台允许的默认应用设置流程；注册可打开格式不等于已经成为默认。界面显示实际探测结果，用户取消设置时不显示成功，安装不改写用户原有默认选择。

## 即时生效与持久化

每次有效选择通过同一设置服务校验、持久化并发布变更。预览和实际控件使用同一套主题数据，不只是修改勾选图形。「完成」关闭设置窗口，不额外提交草稿；不同时提供语义冲突的保存／应用按钮。

配置采用带 `schemaVersion` 的用户级存储，位置由最终平台框架确定，不放进文档目录或工作区。至少保证：

- 枚举和数值做校验，未知配色回退到有效默认值，不能导致应用无法启动。
- 版本迁移保留可理解的未知字段，不因旧版读取而清空其他配置；格式损坏时保留原文件供恢复。
- 写入使用安全替换，避免半份 JSON；失败时不显示「设置已保存」，回滚本次提交并给出可重试反馈。
- 开关、分段、主题卡片和配色色块的鼠标、键盘、辅助功能动作走同一意图，重复选中已选项不产生互斥错误。
- 存储只有用户偏好，不包含文档内容、访问凭据或完整编辑历史。

最小配置形状示意：

```json
{
  "schemaVersion": 1,
  "appearance": { "theme": "system", "accent": "graphite" },
  "desktop": { "externalOpenTarget": "standalone", "standaloneDefaultMode": "reading" },
  "editor": { "wordWrap": true, "autoSave": { "enabled": false, "delayMs": 1500 } },
  "files": { "confirmUnsavedClose": true }
}
```

验收须实际操作控件，检查其他窗口响应、重开设置与跨启动持久化；直接修改配置后控件显示正确只能证明读取路径，不能替代交互验证。
