# 查找、搜索与恢复

## 文档查找与替换

工作区和独立窗口使用同一内嵌查找栏，搜索 Markdown 原文。查找提供区分大小写、完整词、前后导航与匹配计数；定位显示源文并选择对应字符，不把渲染后的列表标号当成原文。替换栏另提供单项和全部替换，空替换值表示删除匹配；第一轮采用字面搜索，不将正则元字符解释为表达式。

替换只进入唯一文档会话，不直接落盘。只读、输入法组合、资源事务、关闭和过期版本均遵循现有拒绝规则；全部替换是一次可撤销编辑。超过文档容量或 10000 个匹配的请求明确拒绝全部替换，不静默执行部分结果。Esc 收起查找栏并返回文档；普通激活不保留焦点外框。

## 工作区全文搜索

文件名筛选与正文搜索分别提供入口。全文搜索只接受显式打开的工作区授权，在后台读取普通 Markdown 文件，不跟随文件或目录链接，不扩大为父目录访问。已打开会话使用其当前缓冲区；组合输入或繁忙的缓冲区计入未完成项，不用磁盘旧版本冒充当前内容。

每次搜索最多检查 20000 个条目、2000 个文档、64 MiB 正文并展示 2000 个匹配；单文档沿用 2 MiB 严格 UTF-8 范围。权限、编码、容量、取消和目录变化均保留提示，不将部分结果描述为完整结果。修改搜索词、切换工作区或销毁视图立即撤销旧结果。

结果包含相对路径、行号与原文片段，通过统一打开路由复用会话。定位前核对目录授权、文件身份和正文摘要；内容变化时保留打开的文件并提示重新搜索，不按旧位置选中无关文字。搜索不修改文件，不批量替换工作区内容。

## 恢复与交付边界

应用每两秒采集一次可读取的会话，在配置目录的独立 `.recovery` 状态文件中后台原子保存；不在用户 Markdown 旁创建文件，不在组合输入或文档事务中读取不完整正文。恢复记录最多 128 个文档／草稿，总体 32 MiB；损坏、未知版本、权限和容量错误保留原记录并反馈，不能通过覆盖或清空恢复记录掩盖失败。内容以普通应用数据保存，不宣称加密或零丢失；异常退出可能丢失最后一个采样周期内的输入。

工作区提供显式的「恢复上次会话」入口，恢复已打开文件、工作区、模式、缩放与可恢复的选区／滚动位置。关闭前最后一份会话描述用于下次选择恢复；用户正常关闭并放弃的修改从草稿记录中移除。尚未处理的上次草稿继续保留，不因本次先打开其他文件而被抹去。忙碌会话保留最后可用采样，不以空内容代替。

未保存内容恢复为独立副本，原文件保持不变。副本的保存与未保存关闭提醒使用另存为，不自动覆盖原路径；自动保存跳过恢复副本。原文路径只用于说明来源，不隐式授予恢复副本新的资源读取范围。另存为成功后，副本成为普通文件会话。

## 自定义快捷键

设置快捷键页与实际窗口动作使用共享命令表。每项可以输入平台组合名称、应用、清空禁用或恢复默认；最多两段组合。普通文字、未知按键和用于界面取消／焦点导航的 Esc／Tab 不作为全局命令绑定。相同组合及多段前缀冲突明确拒绝，不自动抢占其他命令。

有效绑定通过统一偏好服务原子提交，写入成功后才更新现有和新建窗口，失败保留原绑定及未知配置字段。旧配置缺失新分组时使用平台默认值，不误报无效。菜单显示实际绑定；撤销重做仍通过唯一文档会话执行。

新增命令的默认组合与已有自定义绑定冲突时，保留原自定义值，暂时禁用新增绑定并单独提示；不整体恢复默认，也不把这类兼容处理误报成已有设置值无效。

## 安装与默认应用

开发安装由[用户级安装工具](../engineering/user-installation.md)管理，已安装文件、升级和卸载均按归属清单核验，不清理用户文档、设置和恢复草稿。打开方式注册与设置默认应用分开；用户必须在操作系统中主动选择默认值。自动保存仍指向原文件保存流程，不能替代崩溃恢复或人工关闭确认。

新增界面复用共享控件、字号、主题及焦点规则。离屏测试和受控截图不是用户的实际交互验收，待验收的依赖分支不因新增功能而自动合并。
