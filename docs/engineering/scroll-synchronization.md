# 双栏段落映射滚动

工作区双栏使用 `ScrollSyncController` 关联源文与原生阅读控件。进入双栏后自动启用：已有有效阅读映射时，从阅读模式进入保持阅读锚点，从源文模式进入以源文位置关联；离开双栏或隐藏文档时停止处理待执行滚动。独立窗口的阅读／编辑仍各自保留位置，不启用双栏同步。

## 映射与单位

`NativePreviewView` 从当前全局语义模型读取每个可见流所属节点的 UTF-8 起点，与已完成排版的逻辑 Y 坐标关联。相同源文起点的代码行合为一个语义区间；列表段落和表格行使用各自节点，代码从包含工具栏的块顶部起算。文件头尾提供边界。映射按已有有序流二分查找，不另存正文或为每次滚动构建全量位置数组；非单调来源不提供同步映射。

两侧在相邻语义起点之间按各自布局插值。源文一侧使用 Scintilla 的显示行与字节位置，不将 UTF-16 字符数作为源文字节，也不以逻辑文档行数忽略软换行。阅读一侧使用实际排版高度；两侧滚动范围分别收敛，首尾可达。正文、空行、代码、图片、表格的高度差不会被整个文档的滚动百分比掩盖。

向源文设置目标时使用公开的 `SCI_SCROLLVERTICAL` 保留文档行与换行子行，让尚未完成的异步换行继续使用新锚点。只设置显示行号会被控件先前保存的换行后恢复位置覆盖；不通过强制整篇同步换行修正此问题。

建立此锚点后，后续源文滚动也会推进同一书签，包括离开双栏后的源文模式，避免下一次缩放恢复到过时的位置。异步换行与同步都完成后才核对最终位置，不能只检查阅读一侧或固定等待很短时间就判为通过。

这是段落范围内的近似位置关联，不是逐字形等高对应。一个源文行可以对应很高的图片或多个阅读行；阅读一侧保留区间内的小数进度，避免源文行取整后反复回写造成抖动。源文不可见的引用定义、空行等在相邻有效语义区间内处理。

## 代次与通知

同步前同时核验文档 UUID、正文修订、预览请求、路径、资源与已完成布局。校验正文修订前先排除事务和组合输入；会话仍有待发布编辑时刷新修订，旧预览不能继续提供映射。重排、错误、隐藏和关闭时不使用旧几何；发布最新结果后才恢复。

保存后的文件身份重绑定可能发生在会话状态通知中，此时快照按契约拒绝重入读取。预览保留最新刷新意图并立即撤销旧代次，在通知退出或事务／组合输入结束后再取快照；只做合并的队列重试，不在忙碌期间轮询或重新使用旧字节。会话在组合输入进入／退出时发布状态变化，即使取消后没有正文修改，也能唤醒待处理预览。

最后一次明确的用户导航决定驱动侧，滚轮、导航键、滚动条、标题和辅助接口使用各自的导航入口；同侧的滚动通知在事件循环中合并，目标滚动引发的通知被抑制。另一侧迟到的布局通知只能恢复跟随侧，不能反向抢走导航；阅读命令也会确认当前源文选区基线，避免更早的选区通知随后反向抢位。重排和滚动范围变化单独处理；同版本阅读锚点在宽度、缩放和主题重排后按新几何恢复。正文修订变化使旧阅读锚点失效，再以当前源文视口关联新版本。

同步不改变逻辑焦点、源文光标、两侧选区、正文、撤销或保存状态。控制器随承载窗口释放，关闭前停止所属计时器；标签切换与会话接管继续沿用同一个源文与阅读对象。

## 定向验证

按[开发构建](developer-build.md)构建后，以同一构建目录和 Qt SDK 执行：

```text
python scripts/desktop.py test --suite scroll --build-dir build/desktop-admission --qt-prefix build/Qt/6.8.2/msvc2022_64
```

此入口固定 `offscreen`，使用自建临时文件与实际双栏控件，检查 UTF-8、中文／emoji、标题、列表、代码、表格、长段软换行、双向位置、首尾、缩放／主题／宽度重排、失效请求、编辑与撤销、隐藏标签和待执行关闭，以及受影响的预览与接管回归。报告保存在 `evidence/scroll-sync/`，失败同样保留。Unix 按需使用 `scope=scroll-unix`，不重复完整桌面 CI。

离屏几何与合成操作不代替真实滚轮／触控板手感、物理多屏、真实输入法或读屏软件验收。这些结果按[验收规格](../qa/acceptance.md)分别记录。
