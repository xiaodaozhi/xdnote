# 设置窗口与统一偏好

`Preferences` 持有应用级用户偏好，`Appearance` 从同一对象读取主题与强调色；菜单、设置窗口和已打开文档不各自维护另一份可写配置。设置沿用现有用户目录 `settings.json`，窗口几何与导航记录仍分别使用既有侧文件，不写入 Markdown 或工作区。

## 读写与兼容

配置沿用 `schemaVersion=1`。旧版只有 `appearance` 的配置继续可读；缺失的新分组、字段及 `editor.autoSave` 子字段只补运行时默认值，不显示无效值警告。加载使用不插入字段的读取方式，区分缺失值与已存在的空值／错误类型。未知顶层字段、已知分组中的未知字段以及 `editor.autoSave` 的未知字段保留。实际存在但非法的已知字段或分组回退并提示，其他有效选项保留；启动读取不写回文件、不整体重置配置。损坏 JSON、不支持的版本、不可读或超过 64 KiB 的配置保留且拒绝写入，修复后重开应用读取。

每次选择先验证整个变更，再通过禁用直接覆盖回退的 `QSaveFile` 提交；提交成功后才发布变更。目录或写入失败不会先改变文档或控件的当前项，恢复写入条件后可重试原选择。主题与强调色继续共同原子更新；其他分组的更改不覆盖主题，也不重建文档会话。

| 分组 | 当前字段与边界 |
| --- | --- |
| `appearance` | `theme`、`accent` 沿用现有枚举和六色共享参数 |
| `desktop` | `externalOpenTarget` 为 `standalone`／`workspace-tab`；`standaloneDefaultMode` 为 `reading`／`source` |
| `editor` | `fontFamily` 空字符串使用系统等宽字体，`fontSize` 为 8–40 逻辑像素，`lineHeight` 为 1–3，`wordWrap`、`lineNumbers`、`useSpaces` 为布尔值，`indentWidth` 为 1–8 |
| `editor.autoSave` | `enabled` 默认 false，`delayMs` 默认 1500，允许 500–30000 毫秒 |
| `reader` | 空 `fontFamily` 使用系统正文，字号 8–40、行距 1–3，`maxWidth` 为 320–1600 逻辑像素；初始值读共享参数 |
| `files` | `confirmUnsavedClose` 固定为 true，界面不开放静默丢弃开关 |

窗口中的数值菜单提供常用选项；有效但不在菜单预设中的已存值仍按实际值显示。字体来自宿主，不捆绑字体。正文缩放百分比继续是视图状态，在设置基准字号之上应用，不改动界面辅助文字大小。

## 窗口和生效范围

工作区底部设置、独立窗口菜单及 Ctrl+,（macOS 为 Command+,）进入同一非模态实例；关闭后再次进入重建窗口，偏好保持。使用共享标题栏、窗口几何、按钮与菜单；六类页面、筛选、明暗／六色预览及固定底部「完成」不创建另一套文件会话。正文可滚动，窄宽度的色块重排为三列，阅读预览改为上下排列。「完成」关闭窗口，不额外保存草稿。

编辑设置应用到现有与后续源文视图，保留原文、撤销、选区及可恢复的逻辑滚动位置。阅读排版重新规划时仍使用冻结的值对象，不在工作线程访问偏好或界面对象；自动保存开关／延时变更不触发无关排版。只读示例的 Tab 导航不能困在代码控件内。

命令行、IPC 和系统文件打开事件遵循外部打开偏好，工作区内的显式打开仍留在该工作区。重复文件继续通过统一身份登记激活原会话，不迁移已打开文档或覆盖 dirty 缓冲区。独立默认模式只影响新建立的独立文档，改变设置不会跳转已有视图。

文件关联安装／探测、网络图片读取及自定义快捷键仍是独立范围，设置窗口不显示虚假的默认应用状态或可执行的未实现操作。「关于」显示实际 Qt 版本、开发构建状态和既定许可，不伪造发行版本。

## 自动保存

`AutoSaveController` 按文档防抖，共用 `FileDocument`／`FileManager` 的串行保存、冻结快照、文件身份重绑定与外部冲突保护。保存期间继续编辑时，旧版本成功不会把新修改标成已保存；下一轮使用新的快照。未命名文档不会猜测路径，硬链接仍由统一保存服务拒绝并保留原文件。

组合输入、文档事务、资源维护、已有 I/O 或模态选择未结束时延后。只读、冲突或失败后暂停，保留未保存内容与正常关闭保护；不反复自动重试，不循环弹出错误对话框。用户可通过已有提示处理冲突、手动重试或另存为。关闭应用或文档会停止、释放所属计时器。

## 无交互验证

共享输入框、字段下拉、分段、开关、卡片和预览边框遵循[控件统一口径](../visual/design-system.md#控件审查后的统一口径)。全局搜索在正文显示计数、分类与结果卡片，快捷键页另有页内搜索和键帽；第三方许可查看器读取嵌入的清单及许可文本。配置写入失败显示顶部错误条和重试入口，尚未成功写入的值不发布给其他窗口，重试保留原有及新出现的未知字段，不通过重置设置恢复。

使用成功构建的同一目录及 Qt SDK：

```text
python scripts/desktop.py test --suite settings --build-dir build/desktop-admission --qt-prefix build/Qt/6.8.2/msvc2022_64
```

该范围固定 `offscreen`，只访问自建临时配置与文件，覆盖配置迁移／非法字段／失败回滚、实际控件选择、跨窗口同步、搜索、外部打开路由、自动保存的关闭／冲突／硬链接保护与保存期间继续编辑，以及受影响的原生阅读、共享分析流水线、双栏滚动、源文与工作区回归。组合回归同时核对排版设置变化后的分析复用、语义阅读锚点、原文、选区和撤销。报告和明暗六页／紧凑截图进入 `evidence/settings/`，失败同样保留报告。

Unix 使用 `scope=settings-unix` 补验 Linux 与 macOS 双架构，不重复完整桌面 CI。合成控件操作、离屏截图和逻辑几何不是人工视觉、真实读屏、系统选择器或物理跨屏验收；新窗口的最终视觉与实际操作单独记录。
