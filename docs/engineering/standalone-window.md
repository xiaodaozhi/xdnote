# 独立窗口的视觉与交互

独立阅读与编辑窗口采用[当前图组](../../design/hifi/README.md)、[设计系统](../visual/design-system.md)和[精确参数](../visual/tokens.json)。应用标题行、工具栏、格式栏与状态栏共用逻辑尺寸。Windows 使用单层 48 逻辑像素自定义标题栏，包含品牌、文件名及最小化、最大化／还原、关闭按钮，不在上方叠加系统文字标题栏；保留原生缩放、系统移动、DWM 阴影和最大化命中区。普通 HWND 全部属于 Qt 客户区，边缘承担原生缩放命中，正文右侧预留 8 逻辑像素，避免滚动条与缩放区域争抢指针；最大化按当前显示器工作区核对可见客户区。macOS、Linux 的系统装饰与原生文件选择器继续遵循平台约定。工作区复用这些窗口组件，基础范围见[工作区基础](workspace-foundation.md)；完整设置窗口及关联安装由对应任务实施。

## 共享控件与反馈

`Appearance` 提供有效主题、强调色及独立语义色；`SharedButton`、`SharedMenu` 和 `ElidedLabel` 统一默认、悬停、按下、禁用、键盘导航、长文案及焦点归还。按钮只在 Tab／Shift+Tab 进入且需要标明位置时显示外框，指针、激活、Esc、菜单关闭和窗口失活清除外框，保留合理的逻辑焦点及编辑选区。

`UiFonts` 同时提供 Qt 与受限阅读器的系统无衬线字体族。Windows 优先 Microsoft YaHei UI／Microsoft YaHei，macOS 使用系统 UI 与 PingFang SC，Linux 使用系统无衬线与可用的 Noto Sans CJK SC；不另外分发字体。源文保留系统等宽拉丁字形，中文使用无衬线回退。品牌继续使用已验收的 SVG，整个画布显示高度按 `brand.displayHeight` 统一为 19.8 逻辑像素；品牌与文件名按可见字形垂直居中，不修改品牌路径或生成设计图历史副本。

共享菜单与各级子菜单使用透明窗口、8 像素圆角表面和高斯柔化阴影，阴影画布边距为 18 逻辑像素，模糊半径为 12、向下偏移 3，最深透明度不超过 20%。应用只绘制一套表面和阴影，菜单项沿用 QMenu 的键盘、单选、禁用与可访问语义，不叠加平台菜单面板的硬阴影。图标及强调色色块使用相同槽位，靠近屏幕边缘时收敛到可用区。应用自有确认框使用 `SharedDialog`：内容表面宽度遵循窗口参数，外侧 24 像素用于透明阴影，模糊半径为 18、向下偏移 4，包含关闭按钮和父窗口遮罩；原生打开／另存为选择器不使用此外壳。阴影按 DPR 采样并有限缓存，四周在画布边缘归于透明，不得出现右下侧硬黑边或截断。

共享弹出层在平台样式初始化及显示后移除附加的图形效果，防止 Qt Windows 11 样式自动添加的阴影与自绘阴影重叠。测试同时核对最终菜单像素的左右透明度、画布边缘和附加效果，不能只验证阴影生成函数；平台行为依据见 [Qt 6.8.2 样式实现](https://github.com/qt/qtbase/blob/v6.8.2/src/plugins/styles/modernwindows/qwindows11style.cpp#L2007)。标题垂直定位依据实际成形的字形及回退字体边界，兼容中英混排，不以主字体的近似度量代替真实字形。

Windows 标题栏的三个窗口按钮为 48×48 逻辑像素、无间隙贴靠右边缘，使用矩形命中与悬停表面。最小化和最大化／还原使用可见的中性悬停色，关闭悬停为红底白色图标，按下色进一步区分；窗口圆角由系统统一裁切。主窗口显式启用 DWM 非客户区呈现与系统边框、阴影；支持时请求系统圆角，不用区域蒙版破坏系统阴影。Windows 10 不支持的圆角属性保持系统默认，不能把 Windows 11 的属性读取结果当作最低系统验收。接口依据见 [Microsoft 窗口圆角文档](https://learn.microsoft.com/en-us/windows/apps/desktop/modernize/ui/apply-rounded-corners)。

父路径在工具栏面包屑位置显示，窄窗口省略但保留完整可访问名称、提示与路径菜单。文档菜单中的文件位置子菜单提供复制完整路径及打开所在文件夹；这些动作不导入工作区。工具栏图标直接请求「在工作区打开」，保留原会话，且不自动导入父目录。模式切换保持单选，源文工具使用已有矢量图标和可读名称。格式命令通过已有会话写入，不建立第二份正文；只读和不可用动作在界面中禁用。

页脚区分未修改、未保存、保存中、只读、失败与磁盘变化，配合语义标记；源文模式显示行列。正文缩放为每个窗口的 50%—200%，只调整阅读及源文内容，不改变 UI 密度、不改写正文或把显示器 DPR 当成缩放选择。取消、放弃、保存后关闭及失败保留继续遵循[文件契约](file-save-workflow.md)。

干净文档的外部变化提供重新载入及稍后，dirty 文档保留当前编辑并处理冲突。失败提示提供适用的重试或另存为；只读文档明确允许阅读与另存副本。确认框复用统一宽度、文件卡片、按钮顺序与语义色，长正文使用有界滚动，不让普通短说明出现滚动条。

未修改且无冲突时保存不可用；编辑中有修改的保存才作为主要动作。标题工具提供一级至六级标题，修改经会话进入撤销。未保存确认的文件卡包含修改标记，放弃使用次要描边按钮；冲突确认的主要动作是保留当前编辑，重新载入仍须再次确认。只读及外部变更提示条具有图标、语义色和关闭入口，页脚只读锁使用中性色，不能显示为绿色保存成功。

打开状态提供标题、忙碌动画和取消；失败状态保留原因、路径和重新选文件入口。保存与等待关闭使用不表示虚假百分比的动画。保存失败以自有窗口说明权限、占用、硬链接或其他实际原因，提供继续编辑、另存为和适用的重试；保存结果不确定时禁止此窗口直接重试，先核对磁盘和恢复副本。失败不清除 dirty、关闭窗口或丢弃撤销。预览失败使用独立正文状态，提供重新生成和查看源文。

## 外观、原文与阅读位置

文档操作菜单分别提供跟随系统／浅色／深色与六种强调色。`FileApplication` 为已打开和后续窗口提供同一个 `Appearance`；主色、分段、焦点与选区使用强调色，警告／失败／成功使用独立语义色。品牌在明暗背景使用对应已验收的矢量，不按强调色重新着色。

外观保存至 `QStandardPaths::AppConfigLocation/settings.json` 的 `schemaVersion: 1`、`appearance.theme` 与 `appearance.accent`。有效选择使用 `QSaveFile` 替换后再发布变更，写入失败不更改当前外观；未知字段保留，无效枚举回退默认，格式损坏或不支持的版本保留原文件并显示错误。配置不放进文档目录，读取和写入上限 64 KiB。测试显式使用内存或自建临时配置，不访问用户真实设置。

源文的基础标题、围栏和行内代码着色只改变显示样式，不改变字节、版本、dirty、选区和撤销。它不是另一套 Markdown 解析权威，方言与安全边界仍由 Rust 服务和[架构](architecture.md)决定。

阅读页记录稳定滚动位置，重新载入、主题变化和渲染更新后恢复；新内容变短时由浏览器收敛到有效范围。主世界脚本仍禁用，资源与导航仍受精确限制。恢复位置只在 `QWebEngineScript::ApplicationWorld` 执行固定的 `window.scrollTo`，参数为应用取得并限幅的数字，不拼接文档文字，不暴露 WebChannel、文件或网络入口。依据见 [Qt 脚本开关](https://doc.qt.io/qt-6.8/qwebenginesettings.html#WebAttribute-enum)与[隔离世界执行接口](https://doc.qt.io/qt-6.8/qwebenginepage.html#runJavaScript-1)。

阅读区右键菜单只提供产品中文复制、全选，不暴露浏览器后退、保存网页或查看页面源码。任务列表使用主题化的只读复选标记，不额外显示项目符号。代码块包含语言、复制、可用语言的基础词法着色和独立横向滚动，宽表格同样独立滚动。着色不执行代码，未知语言及超过 128 KiB 的单个代码块回退纯文本；渲染仍受原有源文与 HTML 总上限约束。

代码复制按钮由 Rust 生成固定结构，文档 HTML 和语言文本仍转义。固定应用脚本在隔离世界接收真实点击，以每页随机标识、生成版本和数字索引通知 Qt；Qt 重新核对当前会话版本后，读取代码节点的纯文本，经产品剪贴板动作发布。不传入文档脚本、URL 或路径，不启用主世界 JavaScript、WebChannel、网页剪贴板权限或资源读取。复制保持 Unicode 与换行，不改变源文、dirty 和撤销。

## 自动化与验收边界

自动化检查实际窗口的逻辑几何、控件边界、长路径、主题／配色状态、键盘与指针反馈、菜单／确认框取消、只读和失败提示；同时核对源文与撤销不受外观改变影响。阅读验证同时检查 DOM 版本和实际绘制，不能只凭加载完成就记录空白截图。外观组合、读取位置和多采样倍率的证据使用稳定文件名存放于忽略的构建目录或有期限的 CI 工件，不覆盖设计原稿。

按钮显式继承父容器的共享字体，避免平台按控件类别覆盖逻辑字号。弹窗销毁后的下一轮事件再次归还逻辑焦点，不抢占其他应用；焦点自动化先核对保留的目标，再合成 Qt 窗口激活并检查键盘焦点。无窗口管理器的 Xvfb 不能据此证明真实桌面的窗口激活策略，诊断同时记录弹窗返回时的激活状态。

应用自绘按钮关闭 macOS 的原生焦点框，Tab 外框仍由共享绘制控制；像素检查覆盖自动聚焦、激活后及确认框默认按钮，不能只检查内部状态。阅读、源文和长说明的滚动条使用共享颜色与 `controls.scrollbarWidth`／`scrollbarInset`／`scrollbarHandleMin`，避免深色界面出现浅色滚动槽。

矢量图标的普通和高倍率 `QIconEngine` 像素图入口均先清为透明背景，再绘制 SVG；不能只处理高倍率入口，否则标准倍率可能显示未初始化底色。自动化同时检查 1／1.5／2 倍图标的透明角、有效图形与物理尺寸。

`standalone_visual` 纳入统一构建入口的 `test`，输出 `visual-qtest.txt`；与其他 QtTest 报告同样属于必需结果。截图位于 `evidence/standalone/`，`geometry-1.json`、`geometry-1.5.json`、`geometry-2.json` 记录实际 DPR、标题栏／工具栏／状态栏／按钮的逻辑高度及 UI 字号，相应子进程诊断一并保存。不同采样倍率必须保持逻辑尺寸不变；这组测试不执行物理跨屏拖动。

这些检查不代替最低系统、真实输入法／辅助技术、文件管理器关联、原生选择器的人工桌面核验或混合 DPI 物理拖动。上述平台工作分别由[架构准入](architecture.md)、[平台目标](platform-support.md)和[窗口几何](window-geometry.md)跟踪，单文件视觉自动化通过不将其他窗口或发行阶段视为完成。
