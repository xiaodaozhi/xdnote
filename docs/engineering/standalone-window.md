# 独立窗口的视觉与交互

独立阅读与编辑窗口采用[当前图组](../../design/hifi/README.md)、[设计系统](../visual/design-system.md)和[精确参数](../visual/tokens.json)。应用标题行、工具栏、格式栏与状态栏共用逻辑尺寸；系统原生外框另计，窗口按钮和原生文件选择器遵循平台约定。工作区、完整设置窗口及关联安装由对应任务实施。

## 共享控件与反馈

`Appearance` 提供有效主题、强调色及独立语义色；`SharedButton`、`SharedMenu` 和 `ElidedLabel` 统一默认、悬停、按下、禁用、键盘导航、长文案及焦点归还。按钮只在 Tab／Shift+Tab 进入且需要标明位置时显示外框，指针、激活、Esc、菜单关闭和窗口失活清除外框，保留合理的逻辑焦点及编辑选区。

父路径在工具栏面包屑位置显示，窄窗口省略但保留完整可访问名称、提示与路径菜单。菜单提供复制完整路径及打开所在文件夹；这些动作不导入工作区。模式切换保持单选，源文工具使用已有矢量图标和可读名称。格式命令通过已有会话写入，不建立第二份正文；只读和不可用动作在界面中禁用。

页脚区分未修改、未保存、保存中、只读、失败与磁盘变化，配合语义标记；源文模式显示行列。正文缩放为每个窗口的 50%—200%，只调整阅读及源文内容，不改变 UI 密度、不改写正文或把显示器 DPR 当成缩放选择。取消、放弃、保存后关闭及失败保留继续遵循[文件契约](file-save-workflow.md)。

干净文档的外部变化提供重新载入及稍后，dirty 文档保留当前编辑并处理冲突。失败提示提供适用的重试或另存为；只读文档明确允许阅读与另存副本。确认框复用统一宽度、文件卡片、按钮顺序与语义色，长正文使用有界滚动，不让普通短说明出现滚动条。

## 外观、原文与阅读位置

文档操作菜单分别提供跟随系统／浅色／深色与六种强调色。`FileApplication` 为已打开和后续窗口提供同一个 `Appearance`；主色、分段、焦点与选区使用强调色，警告／失败／成功使用独立语义色。品牌在明暗背景使用对应已验收的矢量，不按强调色重新着色。

外观保存至 `QStandardPaths::AppConfigLocation/settings.json` 的 `schemaVersion: 1`、`appearance.theme` 与 `appearance.accent`。有效选择使用 `QSaveFile` 替换后再发布变更，写入失败不更改当前外观；未知字段保留，无效枚举回退默认，格式损坏或不支持的版本保留原文件并显示错误。配置不放进文档目录，读取和写入上限 64 KiB。测试显式使用内存或自建临时配置，不访问用户真实设置。

源文的基础标题、围栏和行内代码着色只改变显示样式，不改变字节、版本、dirty、选区和撤销。它不是另一套 Markdown 解析权威，方言与安全边界仍由 Rust 服务和[架构](architecture.md)决定。

阅读页记录稳定滚动位置，重新载入、主题变化和渲染更新后恢复；新内容变短时由浏览器收敛到有效范围。主世界脚本仍禁用，资源与导航仍受精确限制。恢复位置只在 `QWebEngineScript::ApplicationWorld` 执行固定的 `window.scrollTo`，参数为应用取得并限幅的数字，不拼接文档文字，不暴露 WebChannel、文件或网络入口。依据见 [Qt 脚本开关](https://doc.qt.io/qt-6.8/qwebenginesettings.html#WebAttribute-enum)与[隔离世界执行接口](https://doc.qt.io/qt-6.8/qwebenginepage.html#runJavaScript-1)。

## 自动化与验收边界

自动化检查实际窗口的逻辑几何、控件边界、长路径、主题／配色状态、键盘与指针反馈、菜单／确认框取消、只读和失败提示；同时核对源文与撤销不受外观改变影响。阅读验证同时检查 DOM 版本和实际绘制，不能只凭加载完成就记录空白截图。外观组合、读取位置和多采样倍率的证据使用稳定文件名存放于忽略的构建目录或有期限的 CI 工件，不覆盖设计原稿。

`standalone_visual` 纳入统一构建入口的 `test`，输出 `visual-qtest.txt`；与原有两份 QtTest 报告同样属于必需结果。截图位于 `evidence/standalone/`，`geometry-1.json`、`geometry-1.5.json`、`geometry-2.json` 记录实际 DPR、标题栏／工具栏／状态栏／按钮的逻辑高度及 UI 字号，相应子进程诊断一并保存。不同采样倍率必须保持逻辑尺寸不变；这组测试不执行物理跨屏拖动。

这些检查不代替最低系统、真实输入法／辅助技术、文件管理器关联、原生选择器的人工桌面核验或混合 DPI 物理拖动。上述平台工作分别由[架构准入](architecture.md)、[平台目标](platform-support.md)和[窗口几何](window-geometry.md)跟踪，单文件视觉自动化通过不将其他窗口或发行阶段视为完成。
