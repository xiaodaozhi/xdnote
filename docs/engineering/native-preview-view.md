# 原生阅读控件准入

## 当前范围

`NativePreviewContent` 和 `NativePreviewView` 消费[全局语义模型](native-preview-model.md)，不经 HTML 或浏览器承载，已建立独立的 Qt Widgets／Svg 准入入口。它们尚未接入默认产品 `MarkdownPreview`，不能据此声称现有工作区或独立窗口已经移除 WebEngine。此阶段复用真实共享外观、按钮、菜单、滚动条和视觉参数；不是另一套产品窗口或新的设计尺寸。

派生内容把全局文本位置、行内格式、段落／标题、嵌套列表与引用、静态任务状态、代码和表格分开表达。选择、复制及可访问文本持有全局 UTF-16 位置，不引用可回收的 `QTextCursor`；布局缓存失效、滚动或重排不会销毁选区。源文、撤销、文件保存与会话登记仍由原有模块拥有，本组件不写入文件或修改源文。

## 布局与交互

短单行文本先核对保守宽度，在首次绘制、命中或辅助接口查询时创建真实文档。较长的普通段落按完整字素边界分批创建局部 `QTextDocument`；只消费完整视觉行，尾部未完成行进入下一批，保持连续像素滚动，不按 H1 切节或重解析 Markdown。当前仍有全局几何遍历，长段需要预测量分批行高，**尚未实现最终的后台增量几何和首帧调度**，不能把缓存有界等同于整篇只访问可见文本。

代码按逻辑行处理，长行和表格单元格按有界横向片段绘制；各代码块／表格保留各自滚动位置，支持局部滚动条及横向滚轮／Shift+滚轮。表格列宽按行内字体测量，使用共享对齐、背景和单层边线；任务框由应用生成，不依赖系统字体中的复选框字形。标题、正文、等宽字体、明暗和强调色读取共享规则；系统固定字体实际不是等宽时，使用平台现有等宽字体回退，另保留系统 emoji 字体候选，不捆绑或下载字体。

原生控件接收选择、全选／复制、文本边界移动、链接与代码复制动作。复制通过 `copyTextRequested` 交给协调层，离屏测试核对请求内容，不写系统剪贴板。代码复制保持派生代码的文字与换行；动作以当前快照为准，不使旧按钮或尚未结束的旧指针按下操作应用到新文档。Tab／Shift+Tab 可以到达链接和代码复制，焦点外框只随 Tab 导航出现，激活、取消、指针操作或失焦后隐藏；逻辑目标和选区独立保留。

可访问接口提供只读文档文本、选择、光标位置、字符矩形、点位与滚动查询，不提供可编辑接口。接口寿命跟随控件，文本不跟随缓存销毁。受控接口测试不能替代真实读屏；离屏合成点击、焦点和截图同样不属于真实桌面验收。

## 版本与资源边界

调用方先以 `expect` 提供文档 UUID、正文修订、请求、路径及资源授权代次，再提交同一 `NativePreviewStamp` 的不可变内容。任一字段过期即拒绝展示；新请求立即撤销旧资源、布局和动作，重入关闭也不能使旧复制控件操作新快照。解析／服务错误仍需由后续产品协调层展示，不能让失败的解析任务永远停留在等待状态。

图片输入只接受应用已授权并产生的静态 PNG 和模型中的对应状态，不接受源文目标作为资源地址。读取仅来自传入内存，资源回调从不调用 Qt 默认文件或网络加载。当前再次核对 32 张、32 MiB 编码总量、单图 8192×8192／1200 万像素及总计 2400 万像素；展示时按目标大小缩放解码。受阻状态保留可读原因和替代文字，不把目标路径交给原生文档加载。

局部图片资源使用应用生成的精确标识；单图缩放目标最多 200 万像素，每份局部文档的已解码图片最多 16 MiB。PNG 插件可能先分配原图再缩放，不能将缩放后字节数当作解码瞬时峰值。派生文本整体保护为 8 Mi 个 UTF-16 单位；布局缓存最多 48 份、成本估计总计 8 MiB，宽度测量缓存估计 1 MiB。超出单项缓存容量的活动文档单独暂存一份，不计作缓存通过证明。`cachedEstimatedBytes` 是估计，不包含 Qt 私有分配，也不是整应用内存保证；实际值须结合完整进程采样。

正文链接默认不具备打开其他文档的资格，需协调层显式提交当前授权状态；片段按全局标题 ID 定位。引用分析不完整时保持链接惰性，外部和带 scheme 的目标不会由控件打开。发出的相对文档请求仍须交给既有工作区／文件路由核验，不能绕过路径身份、目录授权或唯一会话。

**现有 `preparePreviewImages`／真实工作区会话到新控件的产品协调尚未接入。** 传入受控 PNG、快照代次和链接授权的测试验证组件契约，不等于真实资源撤销通知、文件路由和会话生命周期已经完成集成回归。

## 仍需准入

超过 4096 个 UTF-16 单位的双向段落尚未解决跨分批的完整双向上下文；单个极大字素簇也可能超过当前布局保护范围。组件明确返回可读失败，原文保留，**不把这两个准入缺口批准为产品的新文件限制**。较短双向段落保留整个段落上下文；普通组合字符和 emoji 按全局字素边界分批。

还需完成长段后台增量布局、极密结构的模型／几何成本收敛、代码高亮、链接等虚拟动作的辅助语义、实际服务桥接、产品协调与其回归，再移除旧预览依赖。Windows 单机结果不替代 Linux／macOS、真实读屏、桌面交互或最终产品预算；未完成项由 [Issue #104](https://github.com/xiaodaozhi/xdnote/issues/104) 继续跟踪。

验证入口见[独立原生准入](../../experiments/native-preview-admission/README.md)。运行、提交身份、时间、内存样本与可复现缺口记录在 Issue／PR 和忽略的构建报告中，本页不累积单次执行记录。
