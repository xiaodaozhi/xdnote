# 原生阅读控件

## 产品承载

工作区、独立窗口和内存准入窗口的 `MarkdownPreview` 统一使用 `NativePreviewContent`／`NativePreviewView`，消费 [Rust 全局语义模型](native-preview-model.md)。产品不生成 HTML 页面、不链接 WebEngine、不启动浏览器进程；Qt SDK 清单只额外安装 `qt5compat`。源文、撤销、保存和唯一会话仍由既有模块负责，阅读控件只持有不可变派生内容。

## 排版、缓存与文字

源文只作一次全局语义解析，标题 ID、引用、块树和范围来自同一模型。派生内容保留全局 UTF-16 文本、格式、列表／引用、任务框、代码、表格和动作；选择、复制及可访问文本不依赖可回收的局部 `QTextCursor`。

实际产品在后台串行规划几何，接收冻结的主题颜色、缩放、尺寸、DPR 和内容，不访问 QWidget、会话或 Appearance 对象。更新、缩放、主题与尺寸变化使旧任务取消；发布前再次核对几何代次。工作线程创建和销毁自己的 QTextDocument，界面线程只接收数值几何。几何仍需遍历全局块，完整布局时间随内容增长；此处不是只访问可见正文的增量索引。GUI 不等待旧任务结束，窗口关闭后结果没有界面接收者。

短单行文本先测量，首次绘制／命中时才创建文档。普通长段按共享的只读全局字素位图和完整视觉行分批，ASCII 内容不分配字素位图，不为前后台重复保留分析状态；双向段落保持整个段落上下文，单个大字素不切断，不新增 4096 或 16384 字符的文件拒绝限制。双向段落和不可分大字素需要更大的活动文档，超过缓存容量时单独暂存一份并复用，实际成本另行测量。代码按逻辑行、表格按单元格横向分片，各块独立滚动；制表符使用八个空格宽度的停靠位置，复制仍保留原字符。代码沿用 128 KiB 装饰预算，较大代码保留原文而不着色。

派生文本保护为 8 Mi 个 UTF-16 单位，语义模型保护为 64 MiB；首轮源文仍为 2 MiB。布局缓存最多 48 份、估计 8 MiB，宽度测量估计 1 MiB。估计不包含 Qt 私有分配，单份活动大文档不计入缓存，不能据此声称整个应用占用 8 MiB。极密表格的全局模型、派生位置和几何随节点数量增长；测试报告同时记录它们和整进程采样，不将源文字节数当作内存预算。

## 交互与辅助接口

正文、标题、等宽字体、任务框、代码／表格、主题及强调色读取共享参数。代码复制按钮、菜单和滚动条使用共享控件。Tab／Shift+Tab 到达链接和复制动作，激活、取消、指针或失焦后清除外框，逻辑焦点和选区独立保留。

只读辅助接口提供全文、选择、光标、字符矩形、点位和滚动；链接与复制动作按需提供虚拟子接口及动作，不开放编辑接口。保留的旧接口核对快照，不能激活新文档的同号动作。受控接口测试不是 NVDA、VoiceOver 或 Orca 的真实读屏验收，后者继续由 [Issue #87](https://github.com/xiaodaozhi/xdnote/issues/87) 跟踪。

## 资源、路由与生命周期

产品桥接沿用 `preparePreviewImages` 和现有 WorkspaceResourceReader 授权，只提交应用已核验的静态 PNG。原生资源回调只接受精确的应用内存标识，从不调用默认文件或网络加载器。仍核对 32 张、32 MiB 编码总量、单图 8192×8192／1200 万像素、总计 2400 万像素；展示按目标缩放，目标最多 200 万像素，每份局部文档解码最多 16 MiB。PNG 插件可能先分配原图，缩放后字节数不代表瞬时峰值。

文档 UUID、正文修订、请求、路径和资源代次必须一致。新快照、文件变化、路径／授权变化和关闭立即撤销旧资源与动作；原生动作还在协调层核对当前会话，防止排队刷新前使用旧修订。引用分析不完整时链接保持惰性。当前文档片段使用全局标题 ID，相对文档请求仍进入既有文件路由和唯一会话核验；外部 scheme 不由预览打开。解析或排版失败显示可读错误，保留原文与撤销。

## 验证入口与边界

[独立原生验证](../../experiments/native-preview-admission/README.md)覆盖全局模型和控件。实际产品的 `python scripts/desktop.py test --suite preview` 定向运行模型、控件、真实图片授权、链接／标题、阅读位置、明暗、缩放和会话回归；`Desktop admission` 的 `scope=preview-unix` 只补充 Linux 和 macOS 两种架构，不运行完整桌面矩阵。源码、工具、二进制摘要、截图与进程测量保存在忽略的构建报告，具体通过记录以 Issue／PR 和当前提交为准。

离屏图、合成输入和 CI 宿主不代表人工视觉、真实读屏、最低系统或物理跨屏拖动已经通过。整进程样本记录私有提交和工作集；约 50ms 采样可能漏掉更短峰值，工作集求和可能重复共享页。最终发行内容、部署和产品常驻预算继续独立核验。
