# 原生预览分析与刷新流水线

## 共享分析与来源范围

产品 `MarkdownPreview` 使用 `PreviewAnalysis` 获取只读分析。Rust `xdnote_markdown_analyze` 对完整快照建立一次全局解析器，在同一事件遍历中生成原生语义模型及精确引用元数据；标题 ID 仍由模型中的全局生成器提供。引用定义跨块解析，不按可见区切片。目标拼写的局部重新准入保留，以验证实体／反斜线解码；同一引用定义的目标范围在该次分析内复用，不能把它误称为完全没有其他解析调用。

既有独立模型、标题、引用入口继续服务各自的诊断、扫描及维护调用；不要求只扫描引用的任务同时生成完整阅读模型。引用改写仍使用完整构造、定义和目标的原快照 UTF-8 范围；没有精确目标范围时保持不可改写，不用字符串搜索替代。`referencesComplete=false` 继续禁止把可能不完整的扫描用于自动引用维护或导航授权。

新 C ABI 返回两份独立所有权的 Rust 缓冲区，以及语义／引用阶段耗时。两份缓冲区均使用 `xdnote_markdown_free` 释放；任一失败不发布部分分析。模型仍使用原版本的二进制协议，Qt 接收端继续校验编码、树及 UTF-8 边界，不依赖 Rust 类型布局。此结果不持有第二份可写正文或撤销历史。

## 复用与资源授权

共享分析键绑定文档 ID、正文修订及 SHA-256；解析配置和模型版本由当前固定进程实现决定，升级配置／格式不得混用旧缓存。进程内相同键的并发请求等待同一分析，不重复全文解析；等待者可单独取消。完成结果的 LRU 缓存按估计保留字节限制为 16 MiB，最多 32 项；单项超预算仍可用于当前请求，但不进入缓存。关闭会话／预览会移除该文档的缓存项。活跃视图与在途调用另有引用，缓存上限不代表完整进程内存上限。

图片或资源上下文变化不改变正文分析键。资源层从共享引用表准备当前图片与链接；每次仍通过受控读取核对当前文档、根目录、实际图片对象及显式图片授权。路径、文件身份、授权和资源代次照常参与发布门控，分析缓存不包含读取权限。未经本次校验的旧像素不得重新显示。

每个预览另有最多 8 MiB、按 PNG 容量及条目开销计费的派生缓存。只有当前资源读取和授权检查通过，且源图片字节摘要相同时，才能复用原始图片解码／静态 PNG 编码结果；变化图片重新解码，不受影响的图片复用。每次引用仍计入原有源字节、输出字节、图片数量与像素配额，缓存命中不绕过配额。它不是 Qt 显示层全部解码像素的缓存，阅读控件的局部文档与图片内存约束继续独立执行。

图片文件监测仍合并短时间通知；目录通知不一定能准确定位单个图片，因此必要的受控读取可能覆盖多项，只对字节变化项重新执行原始解码／PNG 转换。资源上下文更换后使用新的派生缓存，旧任务只能持有自己的旧缓存直至退出。正文、图片状态和导航可用性都未变时，复用原生内容投影；布局继续使用当前主题、宽度、缩放及资源，不复用过期几何。

## 调度、取消与关闭

每个预览保留一个运行任务和最新待处理快照；连续编辑替换待处理意图，不堆积全部中间版本。新修订、图片失效、资源上下文更换和关闭设置旧任务的原子取消令牌。共享缓存等待、解析前、每 128 个解析事件、逐图片读取边界、资源准备结束和投影阶段边界检查取消；取消状态不作为产品错误显示，不发布部分结果或旧动作。

Rust 状态码 `4` 专门表示协作取消，其他状态含义保持原契约。回调与原子令牌仅在 FFI 调用期间有效，不能抛异常或访问 QObject。解析器构造、单次 `next()`、单次受控读盘／图片解码、Qt 接收和内容投影内部仍不能硬中断；阶段取消不保证立即终止任意系统或第三方调用，也没有引入工作进程或宣称操作系统隔离。

关闭后取消当前任务、清除待处理快照和文档缓存，不再发布预览；后台任务只持有只读值、受控资源和自己的缓存，退出后释放。不用同步等待工作线程来阻塞界面。保存／组合输入期间的延迟刷新意图、唯一会话、版本核验及双栏映射继续遵守各自契约。

## 测量与验证

`MarkdownPreview::workStatistics` 暴露诊断数据：队列等待、Rust 语义与引用处理、Qt 接收、资源准备、受控读取、原图解码／PNG 转换、内容投影、布局就绪和最新请求到就绪耗时，以及缓存命中、图片重用、完成／取消计数。Rust 语义耗时包含解析器构造、事件与模型构建；引用耗时包含目标局部准入和元数据编码，不称为纯解析内核时间。布局记录后台调度至就绪的经过时间，不是绘制帧耗时。各阶段可包含调度与共享工作，不能简单相加解释完整应用响应。

[后台验证](../qa/background-validation.md)新增 `pipeline` QtTest 以及 10 KiB、1 MiB、2 MiB 自有样本的流水线探针。每组预热一次、测量七次，记录冷分析、同版本复用、连续八次编辑和双文档可见性切换后的各阶段数据；关闭后检查缓存项与在途分析回收。探针不操作实际工作区标签，真实标签切换行为仍由既有工作区回归验证。`preview_pipeline` 另验证精确范围、并发共享、缓存边界、资源变化／撤销与源文保真；受影响滚动、文件、资源、组合输入与辅助接口回归继续执行。

报告保存源码／依赖身份、样本摘要、逐次数据和有边界的进程峰值工作集／RSS；不把单独进程样本说成完整应用或所有子进程的内存，也不把离屏就绪耗时当成真实键入／滚动体验。护栏位于 `tools/background-budgets.json`，作用是捕获明显回退，不是性能承诺。真实输入、触控板、读屏、最低系统与安装验证继续单列，不因本流水线通过而完成。
