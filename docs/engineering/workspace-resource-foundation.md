# 工作区资源读取与引用分析基础

本页说明受控资源读取、图片导入与预览、工作区引用检查及相对文档链接打开的实现边界。资源实现覆盖 Windows、Linux 与 macOS；图片写入、独立窗口目标选择及诊断与同一引用模型集成，并提供预览确认的移动与引用维护。源码实现、各平台自动化和人工验收分别记录，不以一种平台的结果代替另一种。产品行为以[资源规格](../product/workspace-resources.md)为准，实际平台验收另行记录。

## 引用与路径

Markdown 引用分析使用与预览一致的解析配置，针对不可变文档快照返回文档身份、版本、图片与链接目标、完整使用范围，以及引用式定义的范围。范围以原始 UTF-8 字节计，另提供经语法核验的可选 destination 范围。该范围缺失或歧义时不能自动改写；不得在完整使用范围内搜索目标字符串后擅自修改正文。调用方使用前须重新核验文档身份和版本。

当前固定的解析器对引用展开设置上限。分析器保守标记可能触及上限的结果为不完整；不完整结果不能证明没有引用、扫描全部覆盖或可安全删除资源。解析或输出超限时整体失败，不提供看似完整的部分结果。

只读的快照引用关系构建器接受工作区及扫描代次、枚举覆盖情况，以及带路径代次、文件身份、文档身份和版本的磁盘或会话快照；同一路径存在会话时以会话快照为准。每个已分析来源（包括没有引用的文档）保留来源信息与文本摘要，使用时仍须重新核验实际对象及快照。会话不可用时不回退到磁盘；同一文件身份出现多个路径时标记不完整，存在会话时不将其他路径的旧磁盘内容当成当前内容。工作区外的已打开会话若与根内磁盘文件同身份，无法确认其相对路径基准时同样跳过旧磁盘引用。重复来源、身份或路径代次不符、枚举缺口、分析不完整或无法解析的目标均保留为不完整结果。已知引用保留使用范围、引用式定义、来源行号和词法解析结果；词法命中不等于文件存在、身份一致或授权通过。构建器保持纯分析，不提供写入或安全删除许可。

另外提供只读的实际目录扫描器，供后台任务调用。Windows 按目录句柄枚举，Linux 在授权根对象内使用受限路径解析；拒绝跟随重解析点、符号链接、挂载点及非普通对象。目录在枚举期间变化、对象不可读、无效 UTF-8、额度不足等均记录缺口，保留不完整状态。macOS 的读取与枚举通过仅授权所选目录的独立辅助进程执行，不回退到不受限的普通路径遍历。

扫描器读取 `.md`／`.markdown`，支持可选 UTF-8 BOM；默认跳过 `.git`、`.hg`、`.svn` 管理目录并记录排除项，不因 `.gitignore` 而跳过普通文档。默认最多 50000 个条目、512 个目录、1024 次磁盘文档读取，磁盘与已提供会话快照累计最多 32 MiB；单份源文仍遵守 2 MiB 限制。最多核验 4096 个不同目标的受控元数据，记录存在状态与身份；图片另外受控读取和解码，区分缺失、受阻、损坏、格式不支持及资源上限。每轮最多诊断 32 张图片、累计源字节 32 MiB，触及诊断上限时保留不完整提示；元数据存在不等于图片可用。`assets/images/` 中常见图片扩展名的普通文件列为候选，不自动删除。取消或撤销授权会丢弃来源和引用结果；使用前仍须核对工作区、扫描、路径和会话代次。

每个实际工作区有独立控制器，在界面线程捕获所有相关已打开会话（包括独立窗口）的快照，后台扫描并按代次接收结果。编辑、组合输入、另存为、文件身份变化、关闭和切换工作区会使旧结果失效；连续更新合并调度，取消后等待用户重新检查。文件与目录监听触发重查；无法建立完整监听时明确保留不完整状态及手动刷新入口。当前索引只在内存中保存，不向工作区写配置或数据库，也不承诺跨进程的原子目录快照。

工作区文档菜单中的“工作区引用检查”复用共享菜单，提供扫描状态、重新检查／取消、当前文档出站引用、入站引用位置、缺失或受阻目标、未引用图片候选及覆盖缺口。长列表有显示上限，候选始终不等于可安全删除。入站和问题列表可打开来源并定位；移动／重命名与跨文件维护经下述独立影响计划执行。图片诊断覆盖当前准入格式及额度，不承诺任意格式。

路径服务按 Markdown 目标拆分片段、逐分量解码一次，生成相对于当前文档目录的编码路径，并拒绝词法越界与不支持的外部目标。路径结果仅用于定位候选项，不能作为文件访问授权；平台对象名称、链接及目录项变化由受控读取层另行核验。

## 标题标识与快照

标题分析与预览使用同一解析配置及第 1 版标识算法，结果包含标题级别、正文、唯一标识和源文 UTF-8 字节范围；桌面层同时保留会话身份和版本。使用结果前仍须核验当前会话，旧版本不能用于定位或改写。解析或输出超限时整体失败，不返回假装完整的映射。

算法取标题的行内文本（包括代码文本、链接文本、图片替代文本及作为文字展示的原始 HTML），忽略格式标记；按 Unicode 小写处理，保留字母、数字与下划线，将连续空白和连字符归一为单个连字符并去除两端连字符，移除其他字符。结果为空时使用 `section`。重复或与先前标识冲突时依次添加 `-1`、`-2` 等后缀，始终与该文档中已分配的标识区分；改变前面的标题可能改变后续标识。此规则不声明兼容其他网站。URL 片段按现有路径服务解码一次后与标识比较，例如 `#%E4%B8%AD%E6%96%87` 对应 `中文`。

预览已使用这些标识。独立窗口和工作区的阅读／双栏预览支持激活仅含片段的当前文档链接，例如 `[标题](#中文-标题)` 或引用式等价写法。定位使用当前展示快照的标题映射；链接目标仅解码一次，找不到标题或片段无效时显示提示，源文不变。指针可点击，Tab 可聚焦并用回车激活；焦点外框遵循共享交互规则。

预览只接收应用生成的页面代次与数字编号，不接收文档提供的目标 URL；激活时再次核验文档版本、页面代次及标题位置。引用分析可能不完整或标题映射失败时不提供可激活链接。Windows、Linux 和 macOS 的相对文档链接进入下述统一打开流程；其他外链与协议仍受阻或保持占位。标题选择器使用当前会话映射；锚点变化提供诊断与源文定位，尚不自动批量改写标题片段。

## 相对文档链接打开与标题定位

Windows／Linux 的阅读、双栏预览可点击相对文档链接；源文使用“打开光标处的文档链接”或 `Ctrl+Enter`，普通点击仍用于编辑。两者进入同一打开意图路由：从当前授权根探测源文和目标的实际身份，先查唯一会话，仅新文档才在授权根内读取严格 UTF-8 基线，不核验后重新按裸路径读取。拒绝父路径越界、中间链接／重解析点、非普通文件及非 Markdown 目标；失败保留原文并显示原因。

新文档在原工作区标签页打开；目标已在独立窗口或其他工作区打开时激活已有承载，不覆盖 dirty 原文、撤销或视图模式。独立窗口仅使用文档目录上下文，新目标仍为独立窗口，不隐式打开工作区。目录授权、来源版本、路径或承载在异步期间改变时丢弃该请求。macOS 复用同一会话和打开路由，资源内容由受限辅助进程读取。

片段只解码一次，目标采用其当前会话正文分析中文与重复标题，定位源文并在适用的预览中滚动。目标页面尚未加载时保存带版本的定位请求，页面就绪后再核验；正文改变则不套用旧位置。目标文件可打开但标题不存在时保留文件并提示，不能因为标题失败关闭或覆盖已有编辑。

## 当前工作区文档链接插入

Windows 和 Linux 的工作区编辑模式可从文档操作菜单选择工作区内的 `.md`／`.markdown` 文件，插入相对当前文档的标准 Markdown 链接。所选文件必须是可读取的受支持 UTF-8 文档；后台使用当前根目录授权核验源文与目标实际对象，拒绝越界和符号链接／重解析点。确认后重新检查工作区、源文身份、会话版本和选区；若发生变化则不插入。链接插入构成一次可撤销正文编辑，不保存源文或修改目标文件。

已有选区作为链接文字，特殊方括号和反斜杠进行转义；没有选区时使用目标文件名。当前只接受单行链接文字。macOS 使用相同入口及受控服务。选择文件后可选择整个文档或目标当前正文的标题；已打开目标采用未保存的会话快照，选择结束后重新核验目标版本。独立窗口尚无文档链接选择入口，可编辑标准 Markdown 并激活已授权的相对链接，不隐式引入工作区。文件在核验后仍可能被其他程序改动，激活或索引必须重新核验，不能将插入时的检查当作长期授权。

## 受控读取边界

读取器绑定用户选择的根目录对象，每次读取限制字节数、只接受根目录内的相对路径，并检查授权是否撤销。Windows 基于目录句柄逐级打开，拒绝重解析点和非普通文件，读取期间阻止已检查目录被替换；Linux 使用内核受限路径解析，拒绝符号链接、挂载点和非普通文件，并在读取前后核对根对象。无法满足安全条件或内核不支持时失败，不退回字符串前缀或规范路径比较。

macOS 使用独立的 `xdnote-resource-helper`：在打开的根目录身份核对后，先施加仅允许该目录的文件访问规则，再逐级以不跟随链接的描述符访问，并核对设备与实际对象。辅助进程只接受一次有上限的本地请求，不连接网络；结果及等待时间有界。该进程缺失、限制建立失败或响应丢失时拒绝读取，不在编辑器进程中降级为裸路径读取。读取器本身不验证文档会话归属，调用方仍须关联工作区、文档路径和授权代次，并在异步结果返回时重新检查。

## 当前图片预览

Windows、Linux 和 macOS 的阅读与双栏预览可读取当前授权范围内的相对图片；独立窗口仅使用文档目录，工作区使用所选根目录。先将文档路径对应的实际文件身份与会话绑定的身份核对，再读取图片；切换工作区、另存为或关闭会使旧授权或旧生成结果失效。文档当前未保存文本仍用于解析引用，磁盘文件身份只用于核验其授权归属。

预览接受可用解码插件支持的 PNG、JPEG、GIF 首帧、BMP 和 WebP；SVG、远程地址和无法核验的对象不加载。独立窗口本次主动导入到其他目录的图片只保留该目标的目录授权、身份及内容摘要；授权不扩展为工作区，不授权其他未选择的目录。文档改换位置或关闭后撤销这类授权。每张源图最多 8 MiB、单边最多 8192 像素、单图最多 1200 万像素；单次预览最多处理 32 张、累计源字节与生成字节各 32 MiB、累计 2400 万像素。超限或无法读取的图片显示占位及原因。若引用分析可能不完整，则不提供本次图片结果。

资源在后台受限解码后重新编码为内存中的静态 PNG，原文件不改变。页面仅收到应用生成的临时内存标识，处理器按本页及代次精确匹配并只返回内存数据；网页不能直接访问文件、网络或用户提供的 URL。有效图片与所在目录建立有界变化监听；变化后使旧内存标记失效并重新受控读取，身份、授权或内容摘要不符时显示占位。监听和自动化不代替真实平台验收；重命名维护由独立计划执行。

## 图片导入与安全发布

有授权目录的工作区中，编辑状态下可从文档操作菜单选择图片、将单张图片拖入源文区，或粘贴剪贴板位图。剪贴板同时包含文本时按文本处理，不下载 URL。文件导入按受限大小读取并保留本次读取的原始字节；位图编码为 PNG。导入与预览使用相同的格式和尺寸准入，支持情况仍受可用图片解码插件限制。

仅在执行导入时创建 `assets/images/`；目录和文档的实际对象通过目录句柄核验，拒绝重解析点，不覆盖已有文件。相同内容经逐字节核验后复用，其他重名按摘要和必要的序号另取名称。原始图像先写入受控临时文件并刷新，再以不覆盖的方式发布，结果不确定时保留并报告可能位置。已发布图片不会因撤销、文档关闭或导入后编辑失败而自动删除。

图片准备及发布在后台进行；返回后再核验工作区、文档身份、会话版本与选区，只有仍然有效时才插入标准相对 Markdown 引用，作为一次可撤销的正文修改。图片落盘不等于文档已保存；若位置已变化，则报告图片位置并跳过插入。导入进行中暂不关闭文档，并提示等待完成后重试。独立窗口先显式选择图片目标目录，不创建工作区；目标与文档须能生成标准相对路径，不把跨卷目标伪装成相对引用。Windows 继续使用句柄发布；Linux 与 macOS 的临时写入、刷新及不覆盖发布在独立受限辅助进程执行。Linux 需要可用的 Landlock 文件系统限制，macOS 使用进程目录访问规则；不支持或无法施加限制时明确失败，不降级。临时文件与最终文件分别核验，响应丢失或发布后核验失败报告可能位置，不插入虚假引用，也不自动删除已发布资源。

## 引用定位与路径维护

引用检查中的入站来源及问题项可以打开对应文档并选择原文范围；打开仍进入统一文件路由。定位前核对实际文件身份和当前正文摘要，过期时保留已打开文档并提示重新检查，不使用旧字节偏移。标题诊断使用与预览相同的锚点映射，并优先使用已经打开的当前会话正文。

工作区文档菜单提供“移动或重命名资源”。输入根内原位置和已有父目录下的新位置后，先受控扫描并展示影响：源文件、引用目标的新相对 URL、将写入的未打开文件、仍待保存的打开会话，以及不完整扫描和无法改写项。目标只改写解析器已确认的 destination 范围；共享定义去重，保留链接文字、图片替代文本、标题、代码和其他字节。权限及并发状态在执行时再次核验；存在未覆盖项或选择仅移动时须明确确认相应影响。

执行前冻结本工作区打开会话并串行化文件登记与保存，重新扫描对比来源身份与文本摘要，再核验磁盘基线。移动采用根内同卷的不覆盖重命名；大小写别名按实际目录项核验，必要时经唯一临时位置分两步执行，后一步失败报告该位置。不进行跨卷复制后删除回退。Windows 的文件身份租约优先按文件 ID 持有对象，避免按原路径持有的元数据句柄阻止目录移动；不支持时保留原租约并反馈限制，不释放身份保护强行移动。Windows 移动使用锚定父目录的原生句柄；Linux／macOS 在受限辅助进程中执行。目录、资源目标与来源文档同时映射，目录内互链不重复改写。

打开文档由原会话更新一次撤销事务，保留既有 dirty 内容、保存基线和唯一会话登记，不自动保存；路径变化后更新会话位置。未打开文件在受控根下复用统一保存服务，保留 BOM、硬链接另存为保护、冲突分类和恢复位置。Unix 的文件服务在辅助进程限制内执行；Windows 保存期间固定各级父目录。跨文件没有整体原子事务，逐项记录跳过、失败、已写入、会话待保存和结果不确定，保留失败产生的恢复或暂存文件。

本次窗口存续期间可显式恢复上次记录的已完成项。恢复先核对执行后资源身份、文件保存基线和会话当前正文，再反向移动及更新已成功的正文；旧位置被占用、用户后来改变正文或结果不确定时拒绝猜测覆盖。关闭应用后不承诺跨文件全局撤销；文档各自的撤销仍保留。资源被其他程序改名时只诊断断链，用户可在同一入口显式指定并确认新目标，仅预览修复指向旧位置的引用；不推测移动文档自身的历史相对路径，不按相似名称自动修复。
