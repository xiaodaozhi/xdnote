# 工作区资源读取与引用分析基础

本页说明受控资源读取、图片导入与预览、工作区引用检查及相对文档链接打开的实现边界。Windows／Linux 已接入引用调度与文档链接，macOS 受控读取、其他平台图片写入及移动维护尚未完成。产品行为以[资源规格](../product/workspace-resources.md)为准，实际平台验收另行记录。

## 引用与路径

Markdown 引用分析使用与预览一致的解析配置，针对不可变文档快照返回文档身份、版本、图片与链接目标、完整使用范围，以及引用式定义的范围。范围以原始 UTF-8 字节计，不是可直接替换的目标范围；不得在范围内搜索目标字符串后擅自改写正文。调用方使用前须重新核验文档身份和版本。

当前固定的解析器对引用展开设置上限。分析器保守标记可能触及上限的结果为不完整；不完整结果不能证明没有引用、扫描全部覆盖或可安全删除资源。解析或输出超限时整体失败，不提供看似完整的部分结果。

只读的快照引用关系构建器接受工作区及扫描代次、枚举覆盖情况，以及带路径代次、文件身份、文档身份和版本的磁盘或会话快照；同一路径存在会话时以会话快照为准。每个已分析来源（包括没有引用的文档）保留来源信息与文本摘要，使用时仍须重新核验实际对象及快照。会话不可用时不回退到磁盘；同一文件身份出现多个路径时标记不完整，存在会话时不将其他路径的旧磁盘内容当成当前内容。工作区外的已打开会话若与根内磁盘文件同身份，无法确认其相对路径基准时同样跳过旧磁盘引用。重复来源、身份或路径代次不符、枚举缺口、分析不完整或无法解析的目标均保留为不完整结果。已知引用保留使用范围、引用式定义、来源行号和词法解析结果；词法命中不等于文件存在、身份一致或授权通过。构建器保持纯分析，不提供写入或安全删除许可。

另外提供只读的实际目录扫描器，供后台任务调用。Windows 按目录句柄枚举，Linux 在授权根对象内使用受限路径解析；拒绝跟随重解析点、符号链接、挂载点及非普通对象。目录在枚举期间变化、对象不可读、无效 UTF-8、额度不足等均记录缺口，保留不完整状态。macOS 尚不支持，不回退到普通路径遍历。

扫描器读取 `.md`／`.markdown`，支持可选 UTF-8 BOM；默认跳过 `.git`、`.hg`、`.svn` 管理目录并记录排除项，不因 `.gitignore` 而跳过普通文档。默认最多 50000 个条目、512 个目录、1024 次磁盘文档读取，磁盘与已提供会话快照累计最多 32 MiB；单份源文仍遵守 2 MiB 限制。最多核验 4096 个不同目标的受控元数据，记录存在状态与身份；存在不表示正文可读或图片格式可解码。`assets/images/` 中常见图片扩展名的普通文件列为候选，不自动删除。取消或撤销授权会丢弃来源和引用结果；使用前仍须核对工作区、扫描、路径和会话代次。

每个实际工作区有独立控制器，在界面线程捕获所有相关已打开会话（包括独立窗口）的快照，后台扫描并按代次接收结果。编辑、组合输入、另存为、文件身份变化、关闭和切换工作区会使旧结果失效；连续更新合并调度，取消后等待用户重新检查。文件与目录监听触发重查；无法建立完整监听时明确保留不完整状态及手动刷新入口。当前索引只在内存中保存，不向工作区写配置或数据库，也不承诺跨进程的原子目录快照。

工作区文档菜单中的“工作区引用检查”复用共享菜单，提供扫描状态、重新检查／取消、当前文档出站引用、入站引用位置、缺失或受阻目标、未引用图片候选及覆盖缺口。长列表有显示上限，候选始终不等于可安全删除。入站列表目前展示来源与行号；移动／重命名计划、跨文件改写和完整图片格式诊断尚未接入。

路径服务按 Markdown 目标拆分片段、逐分量解码一次，生成相对于当前文档目录的编码路径，并拒绝词法越界与不支持的外部目标。路径结果仅用于定位候选项，不能作为文件访问授权；平台对象名称、链接及目录项变化由受控读取层另行核验。

## 标题标识与快照

标题分析与预览使用同一解析配置及第 1 版标识算法，结果包含标题级别、正文、唯一标识和源文 UTF-8 字节范围；桌面层同时保留会话身份和版本。使用结果前仍须核验当前会话，旧版本不能用于定位或改写。解析或输出超限时整体失败，不返回假装完整的映射。

算法取标题的行内文本（包括代码文本、链接文本、图片替代文本及作为文字展示的原始 HTML），忽略格式标记；按 Unicode 小写处理，保留字母、数字与下划线，将连续空白和连字符归一为单个连字符并去除两端连字符，移除其他字符。结果为空时使用 `section`。重复或与先前标识冲突时依次添加 `-1`、`-2` 等后缀，始终与该文档中已分配的标识区分；改变前面的标题可能改变后续标识。此规则不声明兼容其他网站。URL 片段按现有路径服务解码一次后与标识比较，例如 `#%E4%B8%AD%E6%96%87` 对应 `中文`。

预览已使用这些标识。独立窗口和工作区的阅读／双栏预览支持激活仅含片段的当前文档链接，例如 `[标题](#中文-标题)` 或引用式等价写法。定位使用当前展示快照的标题映射；链接目标仅解码一次，找不到标题或片段无效时显示提示，源文不变。指针可点击，Tab 可聚焦并用回车激活；焦点外框遵循共享交互规则。

预览只接收应用生成的页面代次与数字编号，不接收文档提供的目标 URL；激活时再次核验文档版本、页面代次及标题位置。引用分析可能不完整或标题映射失败时不提供可激活链接。Windows／Linux 的相对文档链接进入下述统一打开流程；其他外链与协议仍受阻或保持占位。标题片段选择器和锚点变化后的批量修复尚未接入。

## 相对文档链接打开与标题定位

Windows／Linux 的阅读、双栏预览可点击相对文档链接；源文使用“打开光标处的文档链接”或 `Ctrl+Enter`，普通点击仍用于编辑。两者进入同一打开意图路由：从当前授权根探测源文和目标的实际身份，先查唯一会话，仅新文档才在授权根内读取严格 UTF-8 基线，不核验后重新按裸路径读取。拒绝父路径越界、中间链接／重解析点、非普通文件及非 Markdown 目标；失败保留原文并显示原因。

新文档在原工作区标签页打开；目标已在独立窗口或其他工作区打开时激活已有承载，不覆盖 dirty 原文、撤销或视图模式。独立窗口仅使用文档目录上下文，新目标仍为独立窗口，不隐式打开工作区。目录授权、来源版本、路径或承载在异步期间改变时丢弃该请求。macOS 暂不支持受控跨文档打开，明确反馈限制。

片段只解码一次，目标采用其当前会话正文分析中文与重复标题，定位源文并在适用的预览中滚动。目标页面尚未加载时保存带版本的定位请求，页面就绪后再核验；正文改变则不套用旧位置。目标文件可打开但标题不存在时保留文件并提示，不能因为标题失败关闭或覆盖已有编辑。

## 当前工作区文档链接插入

Windows 和 Linux 的工作区编辑模式可从文档操作菜单选择工作区内的 `.md`／`.markdown` 文件，插入相对当前文档的标准 Markdown 链接。所选文件必须是可读取的受支持 UTF-8 文档；后台使用当前根目录授权核验源文与目标实际对象，拒绝越界和符号链接／重解析点。确认后重新检查工作区、源文身份、会话版本和选区；若发生变化则不插入。链接插入构成一次可撤销正文编辑，不保存源文或修改目标文件。

已有选区作为链接文字，特殊方括号和反斜杠进行转义；没有选区时使用目标文件名。当前只接受单行链接文字。macOS 的受控资源读取尚未实现，因此该入口暂不可用；独立文件窗口的链接插入、标题片段选择器及移动维护另待实现。文件在核验后仍可能被其他程序改动，激活或索引必须重新核验，不能将插入时的检查当作长期授权。

## 受控读取边界

读取器绑定用户选择的根目录对象，每次读取限制字节数、只接受根目录内的相对路径，并检查授权是否撤销。Windows 基于目录句柄逐级打开，拒绝重解析点和非普通文件，读取期间阻止已检查目录被替换；Linux 使用内核受限路径解析，拒绝符号链接、挂载点和非普通文件，并在读取前后核对根对象。无法满足安全条件或内核不支持时失败，不退回字符串前缀或规范路径比较。

macOS 的等价受限读取尚未实现，当前明确返回不支持，不以普通文件打开模拟授权。读取器本身不验证文档会话归属，调用方仍须关联工作区、文档路径和授权代次，并在异步结果返回时重新检查。

## 当前图片预览

Windows 和 Linux 的阅读与双栏预览可读取当前授权范围内的相对图片；独立窗口仅使用文档目录，工作区使用所选根目录。先将文档路径对应的实际文件身份与会话绑定的身份核对，再读取图片；切换工作区、另存为或关闭会使旧授权或旧生成结果失效。文档当前未保存文本仍用于解析引用，磁盘文件身份只用于核验其授权归属。

预览接受可用解码插件支持的 PNG、JPEG、GIF 首帧、BMP 和 WebP；SVG、远程地址、工作区外目标及无法核验的对象不加载。每张源图最多 8 MiB、单边最多 8192 像素、单图最多 1200 万像素；单次预览最多处理 32 张、累计源字节与生成字节各 32 MiB、累计 2400 万像素。超限或无法读取的图片显示占位及原因。若引用分析可能不完整，则不提供本次图片结果。

资源在后台受限解码后重新编码为内存中的静态 PNG，原文件不改变。页面仅收到应用生成的临时内存标识，处理器按本页及代次精确匹配并只返回内存数据；网页不能直接访问文件、网络或用户提供的 URL。外部图片变化监测、索引及重命名仍须分别实现和验证。macOS 当前显示占位，不能将其他平台的测试结果作为 macOS 图片能力通过。

## 当前 Windows 工作区图片导入

有授权目录的 Windows 工作区中，编辑状态下可从文档操作菜单选择图片、将单张图片拖入源文区，或粘贴剪贴板位图。剪贴板同时包含文本时按文本处理，不下载 URL。文件导入按受限大小读取并保留本次读取的原始字节；位图编码为 PNG。导入与预览使用相同的格式和尺寸准入，支持情况仍受可用图片解码插件限制。

仅在执行导入时创建 `assets/images/`；目录和文档的实际对象通过目录句柄核验，拒绝重解析点，不覆盖已有文件。相同内容经逐字节核验后复用，其他重名按摘要和必要的序号另取名称。原始图像先写入受控临时文件并刷新，再以不覆盖的方式发布，结果不确定时保留并报告可能位置。已发布图片不会因撤销、文档关闭或导入后编辑失败而自动删除。

图片准备及发布在后台进行；返回后再核验工作区、文档身份、会话版本与选区，只有仍然有效时才插入标准相对 Markdown 引用，作为一次可撤销的正文修改。图片落盘不等于文档已保存；若位置已变化，则报告图片位置并跳过插入。导入进行中暂不关闭文档，并提示等待完成后重试。Linux、macOS 及独立窗口的安全发布与目标目录选择尚未实现，不使用普通路径复制作为替代；这些范围仍由 Issue #50 跟踪。
