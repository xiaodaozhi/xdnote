# 文档辅助操作

这些操作复用原文会话与 Rust 全局分析，不创建第二份可编辑正文，不使用 Chromium。界面风格遵循[设计系统](../visual/design-system.md)；人工视觉、实际鼠标与各平台验收独立记录。

## 专注

文档工具栏和更多菜单提供专注入口，F11 切换；进入后收起文档工具栏、源文格式栏、预览标题及工作区侧栏，保留窗口标题、状态和「退出专注」入口。Esc 在未被编辑控件或输入法消费时也可退出。退出恢复原来的阅读／源文／双栏模式、侧栏选择、文本、撤销和普通窗口几何，不借用最大化实现。进入导航页或 Ctrl+K 搜索时退出专注，避免焦点落在不可见侧栏。

## 大纲

预览标题和更多菜单打开大纲，独立窗口使用正文侧栏，工作区复用左侧区域并可收起返回导航。标题、重复标题片段标识和层级来自 Rust 全局语义分析；异步结果必须匹配当前文档 ID 与修订版，过期结果不用于定位。标题列表按模型显示和过滤，不为大文档的每个标题创建独立控件。源文／阅读定位复用现有标题映射，不改写正文。

## 导出

工具栏提供 HTML 和 PDF。用户显式选择目标后，使用冻结的只读快照异步准备内容，显示处理中状态；未保存修改可以导出，导出成功不会把文档标为已保存。目标必须使用正确扩展名，原文路径／文件身份及当前应用正在编辑的其他目标受保护，写入使用不回退为原位截断的原子替换。导出失败显示原因，保留原文、撤销及已有目标。

HTML 从 Rust 模型生成标题、列表、任务、引用、代码、表格和链接；原始 HTML 按文字转义，不执行活动内容。只保留 HTTP、HTTPS、mailto、片段与标准相对链接；相对链接仍相对导出文件，不进行工作区移动或链接维护。只嵌入现有授权路径已经核验、解码的本地 PNG 数据，未授权或未加载图片保留占位，不联网下载。导出 HTML 限制为 64 MiB。

PDF 使用 Qt 原生 `QTextDocument`／`QPdfWriter`，只接收上述生成内容；资源加载器仅接受已嵌入 PNG，不额外读取外部路径或网络。A4、15mm 页边距和自动换行，超过 1000 页拒绝导出。PDF 排版能力与交互阅读控件有差别，不承诺浏览器级 CSS 或任意 Markdown 扩展；链接、跨页表格和长代码的最终外观仍需独立检查。代码围栏的基础配色只用于源文视图，目前导出不附带语言级高亮。
