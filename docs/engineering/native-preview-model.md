# 原生预览语义模型

## 范围与接入顺序

已选择 Rust 全局解析＋Qt 原生按需布局作为预览主路线，litehtml 核心＋自有 Qt 适配保留备选，候选依据见[方案评估](preview-alternatives.md)。`crates/markdown/src/native_model.rs` 和 `NativePreviewModel` 提供只读模型及 Qt 接收端；产品 `MarkdownPreview` 已在工作区和独立窗口接入原生阅读控件，构建与运行依赖已移除 WebEngine。解析器职责、候选与限制见 [Rust 解析方案](markdown-parsing.md)；模型通过仍不等于真实读屏、完整平台或发行验收通过。

[原生阅读控件](native-preview-view.md)已接入长段按需布局、全局选区、复制和受控产品资源／导航服务，并通过[段落语义范围](scroll-synchronization.md)关联双栏滚动。布局继续遵守现有视觉、会话和资源契约，不沿用试验的 H1 切节或节序号滚动；实际平台、真实辅助技术和部署边界以各项证据分别记录。

## 解析与所有权

`xdnote_markdown_native_model` 接收当前会话拥有的不可变严格 UTF-8 快照。一次 `Parser::new_ext` 处理完整正文，仍为 CommonMark 加表格、任务项和删除线；引用定义由同一个解析器全局解析，不能先切源文再分别解析。模型使用前序扁平树，包含块、行内结构、字面 HTML 和来源范围，不保存布局对象、不打开文件或网络、不执行链接或 HTML。

节点的 `sourceStart`／`sourceEnd` 是原快照 UTF-8 字节半开区间；派生字符串已经过 Markdown 实体、转义、代码空白和换行规则处理，不能把它们的字符位置直接加到来源区间上。紧凑列表可能直接在 `Item` 下包含行内节点，没有额外 `Paragraph`；表头直接包含 `TableCell`，表体包含 `TableRow`。引用定义本身不成为可见块；需要可改写范围时继续使用既有 `xdnote_markdown_references` 契约。

标题 ID 与既有标题映射共用生成器，按整个快照处理中文、空标题及冲突。`Link` 和 `Image` 各自从零全局编号，包含图片替代文本内的链接，与既有引用分析及资源序号一致。模型中的目标和标题均为惰性数据；展示方必须沿用资源授权、路径身份和文档导航策略，不能据此直接读取或激活。

返回值继续使用 `XdnoteRenderBuffer`：`status=0` 成功，`1` 表示输入指针／UTF-8 无效，`2` 表示源文或派生预算超过范围、或方言不被当前模型支持，`3` 表示捕获到解析 panic。任何错误不返回部分模型。Rust 分配的输出只能由 `xdnote_markdown_free` 释放，释放后归零；传入指针仅在调用期间有效。失败不改变会话原文和撤销。

Qt 接收端按索引读取编码数据，不扩张为 `QVariant` 对象树。FFI 入口以共享所有权接管 Rust 分配，不额外复制整份编码；最后一份模型销毁时由 Rust 释放。UTF-8 字节视图随该不可变模型存储有效。接收端核对长度、版本、索引、最短变长整数、树嵌套、UTF-8 边界、元数据与序号，拒绝畸形模型。`decode` 只用于同次解析结果的接收与契约测试，不能把任意同长度旧模型当成当前正文；格式不是可信缓存或持久存储协议。`sourceDigest` 标识调用方提供的正文，不能证明模型来源或资源授权。

异步调用方还必须保留文档身份、正文修订、请求代次、路径和资源授权代次；结果返回时逐项核验，过期结果不能发布。模型自身不持有会话、窗口或第二份可编辑原文，也不替代这些代次检查。

## 版本 1 二进制契约

格式不使用 C／Rust 结构体内存布局，所有定长整数均为 little-endian `u32`。头部固定 32 字节：

| 偏移 | 字段 |
| --- | --- |
| 0 | 八字节魔数 `XDNOTE\0M`，其中 `\0` 为一个零字节 |
| 8 | 模型版本，目前为 1 |
| 12 | 原文 UTF-8 字节数 |
| 16 | 节点数 |
| 20 | UTF-8 字符串池字节数 |
| 24 | 标志，仅 bit 0 为 `referencesComplete` |
| 28 | 节点记录区字节数 |

头部之后依次为变长节点记录区、每节点一个 `u32` 偏移的索引表、UTF-8 字符串池。索引相对记录区起点，第一项必须为零，严格递增；最后一个记录以记录区结束处为界，不允许夹杂或尾随数据。

每条记录依次保存：`u8 kind`、`u8 flags`、固定 `u32 subtreeEnd`、变长 `parentDelta`、变长 `sourceStart`、变长 `sourceLength`，然后是标志指定的可选字段。`parentDelta=0` 表示根，否则父索引为当前索引减该值；`subtreeEnd` 是子树结束后的节点索引，叶节点为当前索引加一。此结构使布局端可以跳过整个不可见子树，无需反复遍历子孙。

变长整数是最短形式的 unsigned LEB128，仅允许 32 位、最多五字节；截断、溢出和多余零组均无效。节点标志 bit 0 表示主字符串、bit 1 表示辅助字符串、bit 2 表示非零 `detail`；其他位拒绝。字符串字段为池偏移与字节长度两个变长整数，唯独标题的主字符串使用两个固定 `u32`，便于在标题结束时原位写入全局 ID。`detail` 为变长整数，未出现时为零。

| `kind` | 语义 | 主字符串 | `detail` |
| --- | --- | --- | --- |
| 1 | Paragraph | 空 | 0 |
| 2 | Heading | 全局标题 ID | 标题级别 1–6 |
| 3 | BlockQuote | 空 | 0 |
| 4 | CodeBlock | 信息串的首个语言标识 | 全局代码块序号 |
| 5 | LiteralBlock | 空；子节点为字面 HTML | 0 |
| 6／7 | BulletList／OrderedList | 空 | 无序为 0，有序为开始编号 |
| 8 | Item | 空 | 0 |
| 9 | Table | 每列一个 `N`／`L`／`C`／`R` 对齐字符 | 列数 |
| 10–12 | TableHead／TableRow／TableCell | 空 | 0 |
| 13–15 | Emphasis／Strong／Strikethrough | 空 | 0 |
| 16／17 | Link／Image | 原始解析目标；辅助字符串为 title | 各自的全局序号 |
| 18–20 | Text／InlineCode／LiteralHtml | 派生文字，HTML 仍为字面文本 | 0 |
| 21–23 | SoftBreak／HardBreak／Rule | 空 | 0 |
| 24 | TaskMarker | 空；静态任务状态 | 0 未选中，1 已选中 |

未启用的数学、脚注等扩展不隐式进入契约；扩展方言或改变字段含义时同步更新模型版本、接收端与测试，不使用 pulldown-cmark 枚举的内存值。

## 资源边界与验证

源文沿用 2 MiB 范围，不附加单段或单表的 64K 限制。编码输出设 64 MiB 完整结果保护，包含头部、记录、索引与字符串；超出时整体失败。该值是防止派生输出失控的上限，**不是产品内存预算**；分配器容量、解析器、临时拷贝、布局及图片解码另占内存。结构极密的文档仍有节点成本，后续须用完整进程测量决定准入，不能仅凭紧凑输出宣布轻量目标达成。

`referencesComplete=false` 与引用扫描共用保守的引用展开预算判断，说明可能受到解析器引用展开保护；不能将缺失的引用判为不存在，也不能据此自动维护源文。它不代表整个模型被截断，`true` 也不证明显示、资源或链接操作已经完成。

独立的[无界面验证入口](../../experiments/native-model-admission/README.md)只构建 Qt Core／Test 接收端，验证最大单段落、单代码块、密集大表、无标题多段、深层嵌套、中文／emoji 字符串、字面 HTML、跨块引用、标题及序号一致性、配额、错误输入和 FFI 释放；源文摘要保持不变。具体运行与提交身份记录在 Issue／PR 和忽略的构建报告中。这里的 emoji 只验证字符保真，不代表字形绘制通过；没有进行桌面 UI、真实读屏或整应用内存验收。
