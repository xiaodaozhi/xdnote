# 许可范围与依赖

项目所有者已确定代码采用 Apache-2.0，并授权确定文档与原创设计素材的许可。项目自有文档与原创设计内容采用 CC BY 4.0，按下表区分适用范围。

| 内容 | 许可与原文 |
| --- | --- |
| 自有软件源代码、构建与工具脚本、技术试验代码 | [Apache-2.0](../../LICENSE) |
| 自有说明文档，包括根目录说明文件、`docs/`，以及设计和试验目录中的说明文档 | [CC BY 4.0](../../LICENSES/CC-BY-4.0.txt) |
| 自有原创设计图、品牌图形、图标、素材、视觉参数、设计提示词及来源记录 | [CC BY 4.0](../../LICENSES/CC-BY-4.0.txt) |
| 第三方代码、依赖、字体和素材，以及另有明确声明的内容 | 各自的许可和使用条件 |

按内容性质确定许可，不仅凭扩展名或目录判断。设计内容即使以路径、参数或数据形式嵌入脚本，其设计内容仍按 CC BY 4.0；执行脚本的软件代码按 Apache-2.0。第三方内容不因纳入本仓库或设计图而获得新的授权；本项目仅许可自身有权授权的部分。

## 文档与设计的使用和署名

[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) 允许复制、分享和改编，包括商业使用；使用者须按许可保留已提供的作者、来源和相关声明，提供许可链接并标明修改。完整条件以[许可原文](../../LICENSES/CC-BY-4.0.txt)为准。

未单列作者的项目自有文档和设计可以使用以下署名，并保留材料中已有的单独作者和来源信息：

```text
文档／设计来源：xdnote 项目及其贡献者
项目：https://github.com/xiaodaozhi/xdnote
许可：CC BY 4.0 — https://creativecommons.org/licenses/by/4.0/
修改说明：如有修改，在此说明。
```

品牌图形的著作权许可与商标权分别处理。CC BY 4.0 不授予商标权，也不表示衍生作品或使用者获得 xdnote 项目官方认可；这是该许可[第 2 节](https://creativecommons.org/licenses/by/4.0/legalcode.en#s2)规定的边界，不另加限制其已授予权利的条款。

## 依赖和交付核验

正式产品的依赖、打包与分发方式仍需在技术选型后确定。发行前按实际交付内容核对第三方代码、字体、素材和运行库的许可及归属声明；随包使用项目设计素材时也须携带适用的署名和许可信息。项目文档及原创设计的许可已经确定，依赖清单、所需 NOTICE 和实际包核验继续由 [Issue #4](https://github.com/xiaodaozhi/xdnote/issues/4) 跟踪。
