# 工作区欢迎页

欢迎页沿用[首次打开与空白文档原稿](../../design/hifi/v2/boards/03-welcome-blank.png)左侧界面，不建立替代布局。主工作区的标题栏、侧栏和页脚继续使用共享组件；欢迎内容位于右侧内容区。原图的像素尺寸不作为逻辑尺寸依据。

## 内容与顺序

内容按「已确认的折光标记、欢迎使用 xdnote、打开一个文件，开始阅读与写作。、打开文件、打开文件夹、新建文档、分隔线、最近打开」垂直排列。品牌、标题、副标题和三个操作在同一中轴居中；最近区域的标题左对齐，无记录时居中显示「暂无最近文件」。不得改成横向操作卡片、工作区状态面板或另一套欢迎文案。

三个操作复用 `SharedButton`。打开文件为主要按钮，打开文件夹为有独立面色的描边按钮，新建文档为无底色图文按钮。三者命中区域同宽，左右边界一致，不能仅以各自文案的自然宽度居中；图标与文字作为一个整体对齐。仅 Tab 导航显示焦点环，指针操作与激活后的规则不变。

## 逻辑参数与适配

`tokens.json` 的 `workspaceWelcome` 登记内容最大宽 480、页面内距 24、品牌标记画布 64、说明字号 16、操作宽 192 和最多三条最近文档。这些是实现的逻辑参数，不是从 PNG 物理像素换算的测量值。欢迎标题读取 `typography.headings.window`，操作读取共享的 32 高度、14 字号和 6 圆角，按钮间距为 8。页内留白使用现有间距序列。

标记使用现有 `mark-light.svg`／`mark-dark.svg`，保持原比例与透明留白；不修改品牌几何。明暗模式复用背景、正文、辅助文字、边线和按钮状态；强调色只作用于共享主要动作，不重新着色品牌。内容在可用区域内居中偏上，窄窗口收敛宽度；纵向空间不足时页内滚动，不能压缩字体、操作高度或隐藏必要入口。

最近文档预览复用最近／收藏页的列表行、文件图标、省略、时间、收藏标记、悬停和键盘状态，每行仍为 64 高。最多显示三条真实记录，不额外插入日期分组；有记录时提供「查看全部」，进入已有最近标签。刷新和路由复用同一存储与会话，不维护欢迎页专用历史副本。

## 操作边界

打开文件进入独立窗口，打开文件夹显式选择工作区。新建文档提供空的未命名独立编辑窗口，初始不标记为已修改；首次保存选择真实位置，输入后保留未保存关闭保护。图板右侧的未命名文档用于内容状态参考，打开目标遵循[现行路由](../product/interaction-spec.md)，不能借欢迎页重新加载目录外文件到工作区。

受控 Qt 截图用于核对布局、主题与尺寸，保留于构建证据目录；不替代真实指针、系统选择器或用户视觉验收。原稿保持稳定文件名，不存储另一套欢迎页设计或历史修订副本。
