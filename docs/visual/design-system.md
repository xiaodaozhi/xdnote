# 视觉设计系统

## 方向与材料权威

界面采用接近白色的正文面、浅灰导航、深色文字、克制的强调色和细分隔线。空间优先留给文档，不加入仪表盘、营销卡片、账号入口或 AI 面板。

当前[高保真图组](../../design/hifi/README.md)包含 33 张图板、89 个页面与状态，沿用主工作区、独立阅读／编辑、外观与配色设置的简洁风格。精确颜色以 [tokens.json](tokens.json) 为准，窗口用途及建议尺寸见 [window-registry.json](window-registry.json)。位图由图像工具生成，存在绘制和文字细节误差，不作为逐像素的运行时事实。

用户已授权按当前图组开展开发。实施时共同遵循产品契约、共享参数与本规范；参考图中公共组件的偶然差异继续按统一规则处理。遇到规格冲突、平台限制或需要实质调整外观与交互时，记录问题、给出具体方案后与用户讨论，不将尚未执行的运行验收记为通过。

图组已覆盖浅深色主界面、独立窗口、设置、菜单、焦点、禁用、错误、关闭确认、冲突与扩展状态；六种强调色有[精确样张](../../design/assets/ui-v2/previews/accent-matrix.png)。完整索引见[界面清单](screen-inventory.md)。独立矢量素材与参考切片的使用方式见[交付说明](asset-handoff.md)，素材几何见[asset-geometry.json](asset-geometry.json)。这些是静态设计输入，原生表现仍待研发后验证。

## 颜色与组件语义

- 强调色名称与配置标识见[设置规格](../product/settings.md)。`base` 是选择器展示的基准色，`light`／`dark` 是对应界面使用的适配值。
- 主要动作使用强调实色和相应前景色；次要动作用中性描边或底色；选中文档使用低对比填充与细标记，避免整块深色干扰阅读。
- 已保存、警告与错误使用独立语义颜色并配合文字／图形。切换配色不能把错误变成普通选中态。
- 代码语法高亮与 UI 强调色分开管理。正文标题以清晰中性文字为主，不把所有标题、正文和数值染成品牌色。
- 共享按钮、开关、单选、下拉和分段控件统一处理尺寸、状态与键盘语义；窗口不分别覆写同类控件外观。

参数中的文字配色需在实际背景上检查对比度，主要文字以 4.5:1、非文字边界与焦点标记以 3:1 作为设计检查目标。不能以单纯看起来更浅代替实际检查。当前参数仍需实机验证，不表示无障碍认证。

## 品牌标记

用户已确认“折光”双色方向：两个填充色块以一条弧形留白分开，浅色与深色背景使用相应明暗版本。标记颜色和应用图标底色见 `tokens.json` 的 `brand`；可编辑几何见[品牌源](../../design/sources/brand-mark.cjs)。品牌标记与界面的六种强调色分别处理，石墨色仍是当前展示选择，不构成永久品牌色锁定。界面图的品牌标记经局部替换，应用图标的实际小尺寸显示与平台效果仍待原生验证。

运行时标题栏的完整 SVG 画布显示高度为 19.8 逻辑像素；品牌与 14 像素文档标题以可见字形中心对齐，不把 SVG 留白计作文字基线。Windows 独立窗口使用包含窗口按钮的单层 48 像素自定义标题栏，三个窗口按钮为 48×48 的矩形、无间隙贴靠右边缘，悬停与按下有明确反馈，不能再叠加系统文字标题栏；其他平台的装饰保持平台约定。

## 逻辑尺寸与密度

所有参数使用逻辑像素。PNG 的宽高是材料元数据，不是窗口大小；DPR 只决定物理采样，不再次放大组件。操作系统窗口装饰按平台原生行为适配，不能把图中的 Windows 按钮直接复制为 macOS 标题栏。

初始参数按 8 单位节奏组织。UI 正文暂定 14，辅助文字 12，源文 14，阅读正文 16；这些是原生实现前的建议值。内容字号、应用辅助字号和系统缩放是独立维度，字号增大时布局可增长或滚动，不能用缩字抵消用户选择。

窗口参数由 tokens 管理，登记表引用同一键，不能维护另一组重复宽高。原生量测后若需修订，更新参数、依据及当前材料摘要；同一设计图使用稳定文件名保留最新版本。

工作区欢迎页沿用现有[首次打开原稿](../../design/hifi/v2/boards/03-welcome-blank.png)的居中品牌、纵向操作和最近区域，具体布局与打开边界见[欢迎页规范](workspace-welcome.md)。三个操作使用同宽命中区域，主要／描边／无底色语义分别保留，不按文案宽度分别居中。

功能图标使用 16×16 原生坐标，常规描边 1.25，圆端点及圆接合；窗口最大化／还原保留方角，粗体／斜体为独立字形轮廓，状态与选中色块允许实心变体。原稿形状依据与同风格推导分别登记在[图标出处映射](../../design/sources/ui-icon-reference.json)，具体约束见[图标规范](iconography.md)。画布尺寸与命中尺寸分别管理：常规图标 16、标签关闭 12，点击区域遵循各自已登记变体；不通过额外透明边框缩小可见图形。

## 跨显示器与窗口尺寸

普通窗口跨不同系统缩放显示器移动时保持逻辑客户区尺寸，尤其从高缩放移至低缩放时，不因旧屏倍率、过期最小尺寸或重复转换被撑大。目标可用区不足时只做必要的尺寸收敛与共享紧凑布局，保留保存、关闭及确认入口；字号、组件几何与系统缩放仍分别管理。临时收敛不覆盖用户正常尺寸偏好，往返不能累计放大。

窗口外框与原生边框按目标屏、状态和平台度量处理，不要求不同平台或缩放下的外框物理像素相同。最大化、贴靠和全屏服从系统；主题、DPI 或装饰刷新不能重复执行初始尺寸补偿。实施、恢复、平台限制及验证层次以[窗口几何契约](../engineering/window-geometry.md)为准，适用于窗口清单中的所有应用自有顶层界面；当前没有实际产品跨屏验收结果。

## 跨界面公共组件一致性

同一公共组件只要出现在多个界面，就遵循同一套视觉和交互规则。主工作区、独立文件、设置、比较、导出及弹窗中实际出现的公共部分，都应按组件的用途与状态复用统一规范；某个界面没有该组件时，无需为了统一而增加它，也不要求各窗口具有相同内容或功能。

在同一平台、主题、强调色、字号与交互状态下，同类组件使用一致的逻辑尺寸、字体、行高、颜色语义、边线、圆角、间距、图标比例、命中区域及状态反馈。对齐和位置以组件所属容器为参照：保持一致的锚点、内边距、基线及相邻元素间距，不要求不同窗口中拥有相同的屏幕坐标。窗口伸缩和长文案可以按共享布局规则重排或截断，不能逐页面微调同一控件的基本样式。

标题栏中的品牌字标与文件名按统一的排版参照对齐，并检查实际可见字形的视觉位置；不同字体的度量差异由共享布局处理，不能只比较文本容器的几何中心，也不能将参考图的物理像素偏移直接作为运行时逻辑尺寸。

| 公共部分 | 统一要求 |
| --- | --- |
| 顶部栏与标题栏 | 相同类型的栏保持一致的高度、内容对齐和边距；品牌标记、标题及操作区采用统一尺寸和相对位置。文件路径等附加信息按窗口职责呈现。 |
| 窗口操作与关闭按钮 | 同一平台、同一类型的窗口操作按钮保持图形、尺寸、间距、命中区域及悬停／按下状态一致，并相对标题栏边缘一致锚定。标签关闭、弹窗关闭和窗口关闭按各自语义使用对应组件。 |
| 底部栏与页脚 | 相同用途的状态栏或页脚保持高度、内边距、文字基线、分隔线和操作区对齐规则一致；状态内容与按钮可因窗口职责不同而不同。 |
| 标签页 | 出现标签的界面复用标签高度、内边距、图标槽、文本与关闭按钮位置，以及活动、悬停、未保存、溢出等状态样式。没有标签的界面不增加标签栏。 |
| 图标、按钮及其他共享控件 | 相同语义使用相同图形、尺寸、描边、颜色语义和对齐方式；相同控件的默认、悬停、按下、禁用与键盘焦点状态使用共享规则。 |

主题和强调色变化时，通过共享参数映射到相应颜色与状态，不要求浅色和深色使用完全相同的颜色值。原生标题栏、窗口装饰和系统对话框遵循各平台的布局与交互习惯；若由应用绘制窗口装饰，同平台同类窗口使用统一实现。不同平台、不同职责的容器或有明确语义的组件变体可以有差异，但必须在规格和共享参数中说明依据，不能因参考图上的偶然差异单独实现。

参考图中同一公共组件的样式或位置不一致时，以本规范和 [tokens.json](tokens.json) 为准；缺失的参数须在实现前统一或明确所需变体，并同步相关窗口登记。主工作区与独立窗口的应用自绘标题栏统一建议为 48 逻辑像素，尚未经过原生量测。独立窗口在标题栏单行显示文件名和必要的未保存标记，父路径放在下方工具栏的面包屑位置；「在工作区打开」使用图标按钮并提供可读名称。独立窗口不因统一而增加标签栏。其他现有参考图保留为静态设计；系统原生装饰仍按平台约定处理。

工作区标签位于 48 像素标题行内，左侧品牌／导航区域宽度读取 `windows.main.sidebarWidth`，不额外叠加一行标签。标签宽度范围、内边距与关闭命中读取 `tabs`，活动页使用正文面，未保存状态使用同一语义圆点，并提供长名称省略和溢出滚动。工作区状态栏跨全窗口宽度；源文格式栏与双栏预览标题使用同一 36 像素高度。工作区复用独立窗口的文档控件，在标题内容、侧栏与三模式切换上按容器职责形成变体。

源文格式栏和双栏预览标题的底边在整个内容宽度内连续，包括分栏拖动区及右侧窗口缩放操作区。`Markdown` 标签与纵向分隔线的间距读取 `controls.formatLabelDividerGap`，标题级别按钮读取 `controls.iconMenuButtonWidth`，显示下拉指示并提供一级至六级标题。

工作区侧栏按「工作区选择、搜索文档、最近打开、收藏、文件夹、底部设置与主题」组织，不能用目录标题和刷新按钮替代整个导航层次。「文件夹」右侧加号打开工作区目录选择，刷新操作收在工作区选择菜单；底部设置打开应用级单一非模态设置窗口，旁侧主题入口保留快速切换。侧栏行高、内边距、分组间隔和导航结果行高读取 `navigation`。导航与树选中态使用强调色浅填充，不能套用主要按钮的实色样式。

标签栏在非活动标签、空白和溢出区域保持连续底边；活动标签仅去掉底边，与下方内容面连接，上边与左右边不可省略。标签顶部贴齐标题行，`tabs.topInset` 为 0；无标签时不显示空标签区域和加号，只保留品牌、原生适配窗口按钮及连续底边，空白标题区域仍可拖动窗口。圆角读取 `tabs`，悬停和溢出按钮随主题变化。侧栏与正文之间采用独立的全高细分隔，不能依赖会被文件树或其他子控件覆盖的父容器边框。完整状态按[工作区界面核对](../qa/workspace-visual.md)逐项检查。

侧栏显示时，首个标签的左边线与侧栏右分隔线共用同一逻辑坐标，不额外留出标签外边距。标签关闭采用紧凑变体：命中区 24×24，图形 12×12，距标签右侧 8，与文字和加号共同垂直居中于完整标题行；具体值读取 `tabs.closeHit`、`closeIcon`、`closeInset` 和 `closeRadius`。长标题按关闭区预留宽度省略，不能依赖系统标签样式放置关闭按钮。此变体与普通 32 像素图标按钮、48 像素窗口按钮分别定义。

标签新增加号与文字、关闭图形共用同一内容区的垂直中心。关闭按钮在切换、新增、关闭、溢出滚动及重排期间均保持共享几何，不能先按系统默认位置显示再延迟移回。

独立窗口与工作区状态栏的正文统一读取 `typography.secondary.size`。缩放按钮使用紧凑变体：上下各留 `controls.footerControlInset`（3）逻辑像素，圆角读取 `controls.footerControlRadius`（4）；从独立窗口接管到工作区后仍保持相同字号与留白。

中性按钮和导航的悬停／按下使用主题的 `controlHover`／`controlPressed`，不能使用与所属侧栏或代码背景相同的填充。选中项仍保留选中标记；禁用、悬停与 Tab 外框分别处理。标签关闭、标签溢出、格式工具栏、侧栏入口及阅读复制按钮共同核对。

阅读正文使用 `typography.reader` 的字号、行距与版心，标题采用中性半粗体和分级间距。列表续行与项目正文对齐；引用使用细竖线和轻底色；行内代码、独立代码面板和表格表头／间隔行保持清晰层次。链接使用主题 `link`，不与普通辅助文字混色。未加载图片在行内显示带图标的紧凑占位，独占段落时显示说明卡片；详细失败原因保留在提示与可访问文本中，不在正文重复铺开长诊断文字，不因此启用远程图片或活动内容。

行高增加的留白在自然文字行的上下均分，不把全部增量放在文字上方。引用、代码、表格和普通正文共用同一行框规则；背景与边框的内距按行框计算，选区、命中和片段衔接使用同一排版位置。代码正文上下各留 12，只有实际溢出时才额外预留横向滚动条槽；表格单元格上下各留 6，高字号行内文本、图片和多行内容必须参与行高计算并完整显示。同一个语义引用块的多段背景和竖线连续，独立引用块之间仍保留间隔。

代码头部属于阅读操作栏，使用 32 高共享控件，语言标签使用辅助字号；复制按钮命中 32×32、图标画布 16，垂直居中于头部，图标画布距面板右侧 12。正文阅读缩放不改变此操作栏的尺寸和字号；代码正文及内距继续随阅读缩放变化。定位使用实际命中尺寸，不保留旧文字按钮的宽度或按宽度比例补偿。长语言标签在复制区域之前省略；横向滚动仅移动正文，头部滚出视口时复制按钮随之隐藏。

工作区工具栏的面包屑采用文档图标及 `文档 / 子目录 / 文件名.md`，包括当前文件名；根目录文档省略子目录，工作区外文档显示 `工作区外 / 文件名.md`，未绑定目录时显示 `文档 / 文件名.md`。路径段使用同一字号与基线，祖先段为辅助色，文件名为正文色；长路径优先压缩祖先段，完整绝对位置保留在提示和文件位置菜单。独立窗口仍在该位置显示父目录。分栏仅绘制 `controls.borderWidth` 宽、使用当前主题 `border` 色的细线；`controls.splitterHitWidth` 是拖动命中宽度，其余区域使用正文背景色，不能使用原生亮色凸起边框。

## 三类窗口

| 窗口 | 结构与重点 |
| --- | --- |
| 主工作区 | 标签、导航、工具栏、源文／预览与状态栏；分栏边界对齐，侧栏可收起 |
| 独立文件 | 文件名和父路径、模式切换、局部动作、单一正文与保存状态；不强制出现资料库 |
| 设置 | 左侧分类，右侧分组；主题与配色分开；选择色块配合当前控件预览 |

窄主窗口收起可选导航或调整展示模式，保留可到达的保存和视图入口。设置窗口变窄时配色色块从一行重排为多行，正文滚动而「完成」保持可达。独立窗口和工作区中的相同控件保持同一字号与命中区域。

## 状态覆盖

焦点样式仅用于 Tab／Shift+Tab 导航中必要的当前位置提示。普通点击、悬停、按下、自动聚焦不显示额外 outline；激活、取消、指针交互或失焦后清除外框。控件逻辑焦点、文本光标、选择与错误边线分别处理，完整时序见[控件交互规则](../product/control-interactions.md)。组件图册中的「焦点」列按此键盘状态理解。

| 组件 | 必须覆盖 |
| --- | --- |
| 按钮 | 默认、悬停、按下、焦点、禁用、执行中 |
| 单选／开关／分段 | 当前选择、非选择、键盘操作、辅助功能、禁用 |
| 文件与标签 | 活动、非活动、未保存、关闭、长名称、溢出 |
| 下拉／菜单 | 展开、键盘导航、禁用、边缘翻转、关闭后焦点归还 |
| 正文 | 空文档、只读、加载失败、长行、代码、中文组合输入、滚动 |
| 文件反馈 | 保存中、保存失败、外部冲突、未保存关闭 |

状态不能仅靠颜色区分。图标动作有可读名称，Tab 顺序与视觉顺序一致，分段、主题和配色维持单选而非若干可独立取消的按钮。

## 设计到实现的交付

1. 阅读需求、交互与窗口清单，确定这次修改的范围和待补状态。
2. 在唯一参数文件定义新值及适用条件，再准备可编辑组件和窗口；不从实现结果反向改写原稿来证明一致。
3. 同时对照主窗口、独立窗口、设置和菜单的字号、行高、图标槽、边距与焦点，不只单独检查一个对话框。
4. 记录逻辑窗口、系统缩放、DPR、字体、渲染后端和实际提交，进行原生几何、行为与人工视觉检查。
5. 设计输入和来源进入 `design`，实际截图及测量进入忽略的 `build/`。检查与限制依照[验收规格](../qa/acceptance.md)记录。

不在初始静态图上填写虚构的“还原率”。对照图和代码读取同一组参数，只能证明参数一致，不能替代独立原稿与真实交互的检查。

设置窗口的分类、主题／强调色卡片及开关使用 `settings` 的共享逻辑参数；页面允许滚动而底部「完成」保持可达。三列／六列色块与阅读预览重排不改变基准字号，不能用缩字隐藏溢出；示例预览与真实文档使用同一控件。

## 控件审查后的统一口径

以下规则统一处理 Issue #126 中的素材冲突，适用于本轮实现和后续复用。原始切片仍作为原稿证据，不把旧切片、透明画布或截图缩放当成新的几何参数；本轮视觉结果仍需用户验收。

| 控件 | 共用口径 |
| --- | --- |
| 次要／危险描边按钮 | 正常态有独立 `surface` 面和 1 像素边框；危险动作使用错误色文字及描边。悬停、按下分别使用 `controlHover`、`controlPressed`，不能与父底面混同。主要动作处理期间保留实色与按钮内转圈，禁用状态另行处理。 |
| 字段下拉 | 高 32、圆角 6，文字从左侧 12 起排，箭头固定距右侧 12；长值省略，完整值保留提示。展开时箭头向上，选项菜单右侧独立显示勾选，不挤占图标槽。 |
| 输入框 | 高 32、边框 1、内容矩形内距 12；边框与样式内距共同形成该值，不将可见字形的首个墨点等同内距。搜索有图标和清除入口，只读／禁用保留可辨状态。 |
| 分段选择 | 外框高 32、圆角 6、浅色导航底；内部留白 2、接缝 2，每段宽 72、高 28、圆角 4。设置的默认模式与文档工具栏使用同一组壳体；原素材的 88 不再作为每段宽度。 |
| 开关 | 轨道 40×22、圆点 16、端部留白 3，命中区 48×32。关闭轨道用辅助文字色，开启用强调色；开启圆点用强调色前景，关闭用面色；禁用轨道使用边线色。 |
| 键盘焦点 | 透明导出留白 4 只用于画布；按钮、输入和卡片的焦点线在各自核心边界内缩 2，线宽 2。开关焦点位于轨道外扩 2，仍在命中区内；带文字复选框围绕完整命中区，素材中的单独字形示意不能套成整行外框。 |
| 分组和预览 | 分组线位于标题上方并贯穿该组内容宽度；每页第一个组标题使用同一顶部节奏。编辑／阅读示例都有独立边框面，阅读面保留「预览」标题；外观示例显示模式选择、文档选中行和开关。 |
| 搜索与快捷键 | 设置全局搜索保留侧栏单一入口，正文显示结果数、分类、命中词和前往设置卡片；无结果显示专用空态。快捷键页另有页内查找，按文件、编辑、视图与导航分类，组合键用键帽；没有实际绑定时写「未分配」。 |
| 菜单和滚动条 | 菜单用单层自绘阴影和透明四角，文字、图标、快捷键、勾选与子菜单箭头分别占槽。滚动条正常使用辅助文字色，悬停／拖动分别读取主题的 `scrollbarHover`／`scrollbarPressed`。 |

标题行继续采用已确认的 48 像素内嵌标签布局；图板中独立的 28 像素命令菜单表示命令分组，不在运行界面额外叠加一行菜单。命令通过现有工具栏和更多菜单承载。

标签拖动超过系统拖动阈值后仅显示一个实色跟随层，原位用轻底虚线占位；鼠标横向跟随，纵向锁定标签行，跨相邻标签中点才排序。邻项平移约 160ms，释放归位约 120ms；Esc 或窗口失活取消并恢复原顺序，边缘停留可滚动。关闭按钮随标签移动且拖动标签不再叠加一枚原生关闭按钮，文字、图标、加号保持原登记中心线。

阅读列表的标号、项目符号与任务框属于装饰，选中和复制排除这些标记；正文中转义的标号和代码中的同类文本保留。任务框以行内中线对齐文字，不按图片底边强行对齐。源码围栏内提供基础词法配色，不修改正文、撤销或文件内容。

具体整改项及证据边界见[控件一致性核对](../qa/control-consistency.md)。
