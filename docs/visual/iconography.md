# 图标规范与原稿依据

功能图标以现有工作区、设置、编辑菜单、插入面板和反馈图板为依据，统一细线、圆角及轮廓比例。[出处映射](../../design/sources/ui-icon-reference.json)登记 90 个图标：56 个有直接原稿局部，34 个按所列家族推导。映射保留原稿 SHA-256 与物理裁切矩形；没有直接出现的图形不称为原图切片，也不把位图尺寸换算成控件逻辑尺寸。

## 几何与角色

- 画布及原生坐标均为 16×16，常规描边 1.25，端点和接合为圆形。参数由 [asset-geometry.json](asset-geometry.json) 管理；不再用 24 坐标图形缩入 16 画布后另加透明留白。
- 以可见轮廓核对占用范围，而非只比较 SVG 文件宽高。设置齿轮以 `(8,8)` 为中心，文档使用折角页形，标题、粗体和斜体使用专门绘制的字形轮廓，不依赖运行字体。左右、上下箭头及撤销／重做成对核对。
- 窗口最大化／还原采用方角，最小化横线位于画布中线；关闭图形由其 12／16 槽缩放，24 标签关闭命中与 48 窗口按钮命中各自保留。普通图标 16 与 32 点击区域分别管理。
- 菜单、文件树与列表图标通过“行顶 +（行高 − 图标高）/ 2”定位；不使用偶数 `QRect` 的整数中心再减半高，从而避免图标槽额外高 1 像素。双行文字的内部排版仍由行项布局负责。
- 任务列表格式图标是单个方框勾选；引用是竖线和向右标记；全选是空心虚线外框。新建文档是空白折角页，另存为沿用原稿中的软盘轮廓；不擅加加号、铅笔或其他原稿没有的附件。
- `window-new` 是叠放窗口，`external` 是向外箭头，`exit` 是出门箭头，`focus-exit` 是退出专注的四角标记，四者不能混用。

## 主题与状态

SVG 的主色为 `currentColor`，通过主题、强调色及语义色着色，导出同形的明暗 PNG 1×／2×／3×。普通图标采用透明背景，按钮底板由所属控件绘制。

| 图形 | 使用规则 |
| --- | --- |
| `check-circle` | 实心圆配镂空勾选，用于已保存及设置写入成功；浅深底面分别形成相应反差，不以空心圆勾或单独勾号替代。 |
| `error-message` | 圆圈感叹号，承载保存、设置等错误提示。 |
| `error` | 圆圈叉号，保留给失败／不可用的独立图形；不冒充原稿中的消息感叹号。 |
| `warning`／`warning-filled` | 分别为轮廓三角与实心三角感叹号；状态待确认与外部冲突按各自原稿角色使用。实心版本用镂空标记，避免深色界面固定白色内标失去反差。 |
| `dirty` | 居中的实心圆点；`status-dirty` 是运行时兼容别名，标题、标签及页脚共同读取素材，不再内嵌另一组半径。 |
| `accent-swatch` | 圆形强调色色块，替代原来的内嵌圆角方块；卡片的选中勾号仍是独立状态。 |
| `spinner` | 三分之四开口环；执行中按钮和独立等待控件旋转同一图形。 |

动态 `colorSwatch` 和未保存兼容名称经共享入口解析，普通、选中、悬停和禁用仍由控件语义处理。输入框、复选框、单选及任务框的状态字形遵循各自组件规格；系统文件选择器与原生平台装饰由系统负责。

品牌字标、折光标记和软件图标沿用已经验收的[品牌源](../../design/sources/brand-mark.cjs)；本次重新导出后与既有批准文件内容一致。品牌画布、应用图标的多尺寸导出和标题栏字标高度不套用 16×16 功能图标规则。

## 维护与验证

1. 编辑 [ui-icon-paths.cjs](../../design/sources/ui-icon-paths.cjs)，同时登记直接原稿或家族推导。保持稳定 ID 和文件名；同一语义的多个用途共用图形，角色有差异时登记变体。
2. 执行 `node design/sources/build-ui-assets.cjs`，更新 SVG、明暗多倍率 PNG、含图标的组件／反馈／空态及当前图册。不将旧版图标或导出包加入设计目录。
3. `node design/sources/review-ui-icons.cjs build/cycle-139-icon-system` 输出原稿／旧 SVG／当前 SVG 的放大对照与轮廓数据；添加 `--focus` 可输出重点对照。旧 SVG 只从该运行目录的 `before/icons` 读取，缺少时明确标为“无旧素材”，不会拿当前图形伪充旧版。原稿截图是物理裁切上下文，放大对照不作为等比例尺寸证明。
4. `npm run check:materials` 核对原稿摘要、映射覆盖、透明 PNG、倍率、素材摘要及所有矢量的边界。边界检查在扩展画布以 4 倍绘制，检查 16 画布以外是否有 alpha 大于 32 的可见像素，避免普通导出掩盖裁断。
5. `allUiIconsRenderAcrossSizesAndDensities` QtTest 实际加载编译进 Qt 的全部 SVG，覆盖明暗主色、12／16／20／24 槽、DPR 1／1.5／2／3，以及禁用绘制、兼容别名、缺失资源；不将空资源或非透明底板视作成功。构建身份包含实际绑定的功能及品牌 SVG，变图后旧构建不能继续通过运行入口校验。

自动化只证明素材完整、实际加载和渲染路径有效，不等于用户已通过视觉验收，也不证明所有原生平台和实际显示器均已验收。对照原稿的最终视觉确认独立保留；此流程不要求重复完整桌面 CI。
