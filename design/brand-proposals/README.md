# 品牌候选

以下三款按用户要求留存，均为品牌与软件图标的静态评审图。图中小尺寸排列用于呈现方向，并非真实像素尺寸下的可读性验收。

| 方案 | 评审图 | 状态 |
| --- | --- | --- |
| A · 折光 | [双色版](a-fold.png) | 用户已确认，作为当前品牌方向 |
| B · 书脊 | [查看](b-spine.png) | 备选，留存 |
| C · 连字 | [查看](c-ligature.png) | 备选，留存 |

A 图使用稳定文件名保存当前双色版；按照仅保留同一设计最新版本的约定，不在项目中另存其单色旧版。生成及调整提示词记录在 [prompts.json](prompts.json)。

评审图中的文字和标记是生成的位图。当前可编辑矢量与各尺寸应用图标见[素材说明](../assets/README.md)；它们按已确认的图形方向重建，原生平台效果仍待验证。
